# Critique agenda — 60 min

Work in progress only. Finished work is a demo, not a critique.

## Before you present
- [ ] State the decision being improved, in one sentence
- [ ] Name the specific feedback you want
- [ ] Have the four states drawn, or say why not

## Format
| Min | What |
|-----|------|
| 0–3 | Presenter frames the decision and the ask |
| 3–8 | Silent read — reviewers look before speaking |
| 8–25 | Response to the stated ask, first |
| 25–40 | Everything else |
| 40–45 | Presenter plays back what they heard |

## Rules
- Cite principles by number. "This breaks 04" is reviewable; "feels off" is not.
- Separate "this breaks a rule" from "I'd have done it differently".
  Only the first is binding.
- The presenter decides. Critique informs, it does not vote.
