Components

Toggle

Stable Last updated Oct 2026

A switch that turns a single setting on or off with immediate effect. One component (Toggle-switch) with three sizes, an on / off state, a disabled state and optional prefix / suffix labels.

Guidelines Specifications Code (opens Storybook in a new tab) Accessibility (coming soon)

At a glance

Try it: flip a setting, or click its name — the whole row is the hit area. Each change applies straight away; there’s no Save button.

Notifications

Large toggles in full-width settings rows. Tab to a switch, Space flips it.

1 · One setting

A toggle controls one on / off setting — never a choice between options.

2 · Instant

The change takes effect immediately. If it waits for Save, use a Checkbox.

3 · Name the setting

The label says what is switched (“Email alerts”), not the state.

Toggle, Checkbox or Radio?

UseWhenExample
ToggleA single on / off setting that takes effect immediately.Email alerts · Show deltas · Auto-refresh
CheckboxThe choice is submitted later with a Save / Apply button, or you’re selecting items from a list.Filter options in a form · selecting table rows
RadioChoosing exactly one of several options.Weekly · Monthly · Quarterly

Writing content

  • Name the setting — a short noun phrase: “Email alerts”, “Show deltas”, “Auto-refresh”. Not a verb (“Turn on alerts”) and not the state (“On”).
  • Sentence case, no full stop. Keep it to one line.
  • Describe the on state — the label should say what you get when the switch is on (“Compare to last period”).
  • Disabled reason — one short sentence of helper text below the label: “Available on the Pro plan.”

Behavior & accessibility

TopicWhat to do
ApplyFlip and apply immediately. If saving can fail, revert the switch and show an error.
Hit areaThe whole row — label and switch — toggles. Connect the label to the switch.
Rolerole="switch" with aria-checked="true | false" on a <button> (or <input type="checkbox" role="switch">).
KeyboardTab focuses the switch; Space (and Enter on a button) flips it. Show a visible focus ring — the Figma component has no focus variant.
HoverNot in the Figma component. In code the track darkens one step: Secondary-text/200 off, Primary/700 on.
DisabledUse the disabled attribute so it leaves the tab order, and put the reason in helper text linked with aria-describedby.
No visible labelGive the switch an aria-label that names the setting.
