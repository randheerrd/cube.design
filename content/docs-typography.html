Typography

Stable Last updated Oct 2026

One typeface, DM Sans, set through three groups — Heading, Body and Small — that cover every piece of text in the product. Each size carries one recommended line-height, so choosing a style is a single decision, not three. The Specifications tab lists every value.

Overview

All product text uses one typeface — DM Sans — through a set of text styles. Each text style is built from typography variables, so sizes, line-heights and spacing stay consistent everywhere.

Typeface: DM Sans

A geometric sans-serif with clear numbers — good for dense dashboards. Used for both titles (Family/title) and body (Family/body).

How to read a style name

Every text style name has up to three parts.

Body

Group — Heading (titles), Body (content), Small (labels, captions)

/
B3

Size step — H1…H6, B1…B3, S0…S2. “-Compact” = line-height equal to font size

/
Medium

Weight — Regular · Medium · Semibold · Bold, plus -Italic versions

Download the font

Cube uses a lightly modified build of DM Sans. The only change is the rupee sign ₹, redrawn. Install it on your machine for design work, or load it in code so prices and metrics render the same everywhere.

₹3.2 CrStandard DM Sans
₹3.2 CrCube DM Sans (RupeeFix)
DMSans-RupeeFix.ttfRegular · TTF, 233 KB DMSans-Italic-RupeeFix.ttfItalic · TTF, 277 KB

How to install

  • Figma / design tools: download both files, double-click each and choose Install Font, then restart Figma.
  • Web: host the files and load them with @font-face (below). Keep the Google Fonts link as a fallback.
@font-face {
  font-family: "DM Sans";
  src: url("/fonts/DMSans-RupeeFix.ttf") format("truetype");
    font-style: normal;
}
@font-face {
  font-family: "DM Sans";
  src: url("/fonts/DMSans-Italic-RupeeFix.ttf") format("truetype");
    font-style: italic;
}

Compact styles

“-Compact” styles set line-height = font size (12/12, 10/10). Use them only inside fixed-height elements (table cells, badges, chips) where extra line-height would push content off-centre. Never for multi-line text.

Italics are available for Body and Small styles. Use them sparingly — for helper text, “Click to expand”, footnotes and placeholder-like hints. Never for headings or numbers.

Usage

Reach for the shared tokens rather than a hardcoded family, weight or size — the same styles used to generate every sample on this page:

import { HEADING_STYLES, FONT_FAMILY, FONT_WEIGHT } from './atoms/typography';

// Use tokens directly
const style = {
  fontFamily: FONT_FAMILY.title,
  fontWeight: FONT_WEIGHT.semibold,
  fontSize: 24,
  lineHeight: '32px',
};

See the Typography atom in Storybook for the full token set and every style rendered live.
