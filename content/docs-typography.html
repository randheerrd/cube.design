Typography

Stable Last updated Sep 2026

Three groups — Heading, Body and Small — cover every piece of text in the product. Each size carries one recommended line-height, so choosing a style is a single decision, not three. The Specifications tab lists every value.

Overview

Every type style in Cube belongs to one of three groups, each named by role rather than by raw size — 53 styles in total, all set in DM Sans:

GroupSizesPurpose
HeadingH1 – H6, H6-MediumTitles — page, section, card and panel headings, largest to smallest. Bold by default.
BodyB1, B2, B3 (+ B3-Compact)Anything a person reads at length: paragraphs, table cells, form values.
Small & LabelsS1 (+ S1-Compact), LT1, LT2Supporting text below body size: timestamps, dense-table cells, uppercase tags and badges.

The Heading family and the Body family both resolve to DM Sans today, but are kept as two separate tokens (Family/title, Family/body) so either can change independently later without touching the other.

Why the scale looks like this

The scale was deliberately simplified down to three named groups with a predictable size order (H1→H6, B1→B3) and one recommended line-height per size, to cut down on decision fatigue, keep the product visually consistent across modules, and make the system easier to extend. The one exception is the smallest sizes, which also carry a Compact line-height for the rows of a dense table — reach for it only when a real density problem shows up, not by default.

Usage

Reach for the shared tokens rather than a hardcoded family, weight or size — the same styles used to generate every sample on this page:

import { HEADING_STYLES, FONT_FAMILY, FONT_WEIGHT } from './atoms/typography';

// Use tokens directly
const style = {
  fontFamily: FONT_FAMILY.title,
  fontWeight: FONT_WEIGHT.bold,
  fontSize: 24,
  lineHeight: '32px',
};

See the Typography atom in Storybook for the full token set and every style rendered live.

Small & Labels

S1 is dense UI's default body-adjacent size. LT1 and LT2 are a different job entirely — set in uppercase with wider tracking, for a tag or a status badge, never for a sentence.

Weight and italics

Weight

  • Bold — every heading by default, and a Body/Small value that needs to stand out (a total, a name).
  • Semibold — a Body/Small emphasis one step below Bold — the workhorse weight for a label or a highlighted cell.
  • Medium — a lighter emphasis, and H6-Medium for a title that should read lighter than a Bold one beside it.
  • Regular — the default for body and small text. Never used for a heading.

Italic

Italic exists on every Body and Small style, but is reserved for a secondary note beside the main content — a footer caveat, a data-freshness note — the same job italic already does in the Tooltip footer. It is not a substitute for a smaller size or a lighter weight. LT1/LT2 labels carry no italic — a tag or badge is never emphasized that way.

When to use

Do

  • Step down one heading level at a time (H2 inside an H1 page, not H2 straight to H4).
  • Reach for a heavier weight before a bigger size when something just needs to stand out.
  • Use a Compact style only where rows are genuinely tight — it reads noticeably denser.

Don't

  • Skip a heading level to get a size that "looks right" — fix the hierarchy, not the symptom.
  • Use Bold on body or small text for emphasis — that is what Semibold is for; Bold is a heading weight.
  • Set a whole sentence in italic — it is for a short secondary note, not a paragraph.
