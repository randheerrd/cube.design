Scale

21 steps. One value, three names: the Figma variable designers bind, the CSS custom property this site uses, and the SPACING atom from ./atoms/spacing in code. Each name carries its pixel value, so Spacing/16, --spacing-16 and SPACING[16] are always 16px.

Usage rules

CaseWrite it asNotes
Padding, margin or gappadding: var(--spacing-12) var(--spacing-24)In Figma, bind Spacing/N to auto-layout padding and gap.
Padding inside a 1px borderpadding: calc(var(--spacing-8) - 1px)The border plus padding lands on the token, so the content sits where Figma puts it (messages, segmented tabs, outlined icon buttons).
Room for an iconpadding-right: calc(var(--spacing-8) + 14px)Gap token plus the icon’s width.
Negative marginmargin: -1px 0Only to overlap a border; keep it raw.
Value off the scale (3, 5, 7…)Use the nearest stepUnless it offsets a border — then use the calc() form above.

Source

21 values, defined as Spacing/N variables in the Scale (Px) collection of the Cube Core Figma library (scoped to Gap, which covers auto-layout padding and gap), declared as --spacing-N at the top of the site’s docs.css, and mirrored in the Spacing atom in Storybook, the canonical source for every value on this page.
