Input

Stable Last updated Oct 2026

A single-line or multi-line text field, in three sizes and five states. Pick a size and decide which optional parts — prefix, suffix, helper text — the field needs; the Specifications tab lists every token.

Guidelines Specifications Code (opens Storybook in a new tab) Accessibility (coming soon)

Dimensions

Width is parent-driven — the field fills its container. Only height, padding and font scale across sizes. Label and input text reuse the same tokens as Typography: the Small label is S1 (10/12), everything else is B3 (12/16) except the Large input value, which is B2 (14/18).

React API

Imported from components/PerfSharedUIComponents/primitives/InputV1 as InputV1 (Default/Chips-adjacent single-line) and TextAreaV1 (Text area).

import { InputV1, TextAreaV1 } from 'components/PerfSharedUIComponents/primitives/InputV1';

<InputV1
  size="medium"
  label="Field label"
  isMandatory
  placeholder="Enter text..."
  value={value}
  onChange={handleChange}
/>
