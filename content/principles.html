02 — Principles

Eight rules that can lose an argument for you.

Cite them by number in critique. Every one has a stated exception except the fourth.

/ The eight

What we hold each other to

/01

Show the work

Every number traces to where it came from, in one interaction.

/02

One decision per screen

A screen answers one question. The rest is context.

/03

Default to the boring pattern

Novelty is a cost every user pays, forever.

/04

Make the machine's certainty visible

Predicted, estimated and recorded values never look alike. No exception to this one.

/05

Glance, scan, dig

Three depths, in that order, on every dense surface.

/06

Never block on the AI

Every automated path has a manual one beside it.

/07

Words are the interface

Copy is design work, written by the designer.

/08

Four states or it does not ship

Empty, loading, error, overflow.

/ The test

A rule you cannot lose an argument to is decoration.

Which is why each one carries its own exception

Rules say what good looks like. The process says when it is done.
