Tooltip

Stable Last updated Oct 2026

A Standard Tooltip gives a short line of extra text; a Trendline Tooltip is a small dark card with the exact numbers behind a chart mark. The Specifications tab lists every value.

Guidelines Specifications Code (not in Storybook yet) Accessibility (coming soon)

Source

Values come from the Tooltip — Documentation frames in the Cube Core Figma file (Anatomy, Property, Color Annotation, Dimensions, API, Usage Guidelines) and the live Tooltips components. Figma has no “How to use” frame for Tooltip.

Where Figma disagrees with itself (this site follows the component): the trendline fill #1c1e1f isn’t bound to a token. The API writes Align as “Left- | Right ->”; the values are “Left <-” and “Right ->”. The footer property is “Show Information ” with a trailing space, and the default footer text is misspelled “Informartion”; “Cursor Pointor” is also misspelled. The standalone .Tooltip-header uses padding 8 / 10 and Bold 12, but inside the trendline it is 6 / 10 and SemiBold 12/16 (used here). The cell’s default delta points down (red) while the docs show green. The doc lists the templates as one set, but on the canvas they are separate components. Single-line hover tooltips have no maximum width.
