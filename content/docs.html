Components

Button

Stable Last updated Sep 2026

A clickable control that triggers an action. Three families — Action, Neutral and Accent — share one anatomy: a container, optional prefix and suffix icons, and a text label, plus an icon-only mode.

Guidelines Specifications Code (opens Storybook in a new tab) Accessibility (coming soon)

At a glance

Three decisions set every button: how important the action is (Variant), what it means (Action Type) and how much room it has (Size). Get those right and the rest — states, colour, spacing — comes from the component.

One Filled primary, a Neutral Outlined secondary, a Naked tertiary — the hierarchy most screens need.

1 · Emphasis

One Filled per view. Outlined or Neutral for secondary, Naked for tertiary and inline.

2 · Meaning

Core to proceed, Destructive for anything irreversible, Supportive to confirm or approve.

3 · Room

Large for page CTAs and forms, Medium (default) almost everywhere, Small in dense tables.

Anatomy

Every family shares one anatomy: a container, an optional prefix icon, a text label and an optional suffix icon. Shown: Action / Filled / Core / Large / Comfortable with prefix and suffix enabled.

#ElementFigmaCodeNotes
1ContainerVariant, Size, Height & Spacing, Roundedvariant size density roundedAuto-layout frame that holds the content. Carries fill, border, corner radius, height and horizontal padding. Width hugs the content.
2Prefix iconShow Prefix · Prefix ValueprefixOptional leading icon (instance swap). On by default and defaults to Plus; swap in any icon from the library.
3LabelButton TextlabelDM Sans SemiBold; size scales with Size. A short, verb-first action — “Save”, “Add filter”.
4Suffix iconShow Suffix · Suffix ValuesuffixOptional trailing icon. Off by default and defaults to CaretRight; use it for dropdown and navigation affordances.

Icon-only

With Icon-Only = Yes the label and suffix are removed and the container becomes a square (width = height). There's no visible text, so it always needs an accessible name and a tooltip.

#ElementFigmaCodeNotes
1ContainerIcon-Only = Yes<IconButton>Square — 40 / 36 / 32 / 28 / 24 / 20 px depending on Size and Height & Spacing. Rounded = Yes makes it a circle.
2IconPrefix Valueicon + ariaLabelA single icon, sized by Size: 16 / 14 / 10 px.

Button families

Three component sets share the same anatomy and API. Pick the family by intent first, then configure its Variant.

Action

Primary, destructive and supportive actions. The only family with an Action Type axis.

FigmaButton/Action-ButtonCodeintent="core"…

Neutral

Low-emphasis, colour-neutral actions — Cancel, Filters, Export. Adds a Dashed variant and a Dark mode.

FigmaButton/Neutral-ButtonCodeintent="neutral"

Accent

Tinted, category-coded actions in 8 accent colours. Sizes Medium / Small / Tiny; no Pressed state.

FigmaButton/Accent-Button

Variant

How important the action is. Filled is the highest emphasis, Outlined is secondary, Naked is the lowest.

Filled Default

Primary action on a surface. Use at most one Filled Core button per view or section.

FigmaVariant=FilledCodevariant="filled"

Outlined

Secondary action next to a Filled button, or a standalone action of medium weight.

FigmaVariant=OutlinedCodevariant="outlined"

Naked

Tertiary and inline actions — “View all”, table row actions, links inside cards.

FigmaVariant=NakedCodevariant="naked"

Action type

What the action means. It picks the colour ramp every Variant and State draws from — so the colour itself tells people what will happen.

Core Default

Neutral-positive actions — Save, Apply, Continue. Primary colour ramp.

FigmaAction Type=CoreCodeintent="core"

Destructive

Irreversible or risky actions — Delete, Remove, Revoke. Error colour ramp.

FigmaAction Type=DestructiveCodeintent="destructive"

Supportive

Confirming and success actions — Approve, Mark as done. Success colour ramp.

FigmaAction Type=SupportiveCodeintent="supportive"

Size

Size sets the font size, icon size and corner radius. Height comes from Size together with Height & Spacing. Keep every button in a group the same size.

Large

14px text, 16px icons, 8px radius. Page-level CTAs and forms.

FigmaSize=LargeCodesize="lg"

Medium Default

12px text, 14px icons, 6px radius. Toolbars, cards, dialogs.

FigmaSize=MediumCodesize="md"

Small

10px text, 10px icons, 6px radius. Dense tables, filter bars, inline controls.

FigmaSize=SmallCodesize="sm"

Height & spacing

How dense the container is. Fit Content is available on the Naked variant only.

Default Default

Compact height and padding — 36 / 28 / 20 px tall (Large / Medium / Small).

FigmaHeight & Spacing=DefaultCodedensity="default"

Comfortable

Roomier height and padding — 40 / 32 / 24 px tall.

FigmaHeight & Spacing=ComfortableCodedensity="comfortable"

Fit Content

Naked only. No padding; height hugs the text — for inline, link-like actions.

FigmaHeight & Spacing=Fit ContentCodedensity="fit"

State

Default is the resting state; the others come from interaction. In code, Hovered and Pressed come from pointer events — you only ever set disabled.

Default

Resting state.

FigmaState=Default

Hovered

Pointer over the button. One step darker on the ramp.

FigmaState=HoveredCode:hover

Pressed

While the button is being clicked or tapped. Two steps darker.

FigmaState=PressedCode:active

Disabled

Not interactive: disabled tokens, no pointer events. Explain why nearby — the button can't.

FigmaState=DisabledCodedisabled

Rounded & icon-only

Shape modifiers that combine with every Variant, Size and State. Keep one shape per group.

Rounded = No Default

Default. 8px (Large) or 6px (Medium / Small) corner radius.

FigmaRounded=No

Rounded = Yes

Pill shape — 100px radius. For chip-like or floating contexts.

FigmaRounded=YesCoderounded

Icon-only

Square button with a single icon. Requires a tooltip and an aria-label.

FigmaIcon-Only=YesCode<IconButton>

Icon-only + Rounded

Circular icon button — FABs, compact toolbars.

FigmaIcon-Only=Yes, Rounded=YesCode<IconButton rounded>

Neutral variants & mode

Neutral buttons carry no colour meaning, so they sit calmly beside a primary action. Every variant also has a Dark mode for dark surfaces.

Filled

Highest-emphasis neutral. Dark fill, light text.

FigmaVariant=FilledCodevariant="filled"

Outlined Default

Secondary actions like Cancel.

FigmaVariant=OutlinedCodevariant="outlined"

Dashed

“Add new” and empty-slot actions.

FigmaVariant=Dashed

Naked

Lowest-emphasis neutral. Toolbar and inline actions.

FigmaVariant=NakedCodevariant="naked"

Mode = Dark

Inverted tokens for dark surfaces (shown: Outlined).

FigmaMode=Dark

Accent colours & sizes

Accent buttons code categories — channels, segments — in 8 colours × Filled / Outlined / Naked. They use their own compact scale (Medium 24px, Small 20px, Tiny 16px) and have Default, Hovered and Disabled states only.

Keep one colour per meaning across the product — if Instagram is pink on one screen, it's pink everywhere.

Variants

Filled is a tint (/100 fill, /700 label); Outlined adds a /200 border; Naked is label only.

FigmaVariant

Sizes

Medium, Small and Tiny — 24 / 20 / 16 px. No Height & Spacing axis.

FigmaSize=Medium | Small | Tiny

Accent, Dashed and Neutral Dark mode aren't props on the Storybook Button today. Check with engineering before designing with them, or treat them as a request for the component.

Common layouts

Set up a clear hierarchy: one Filled primary action, Outlined or Neutral for secondary, Naked for tertiary and inline actions.

Do's and don'ts

Emphasis

Do

Use one Filled primary per view and pair it with a lower-emphasis secondary.

Don't

Don't place two Filled Core buttons side by side — people can't tell which action is primary.

Meaning

Do

Use Action Type = Destructive for delete, remove and other irreversible actions.

Don't

Don't use Core (blue) for destructive actions — the colour must signal risk.

Labels & sizing

Do

Keep labels short and verb-first, and keep every button in a group the same Size.

Don't

Don't use vague or long labels, and don't mix sizes within one group.

Writing labels

  • Verb first, specific object. “Save changes”, “Delete report”, “Add filter” — not “OK”, “Yes” or “Click here”.
  • One to three words. Width hugs the label, so long text makes long buttons.
  • Name the object on destructive actions when you can — “Delete report”, not just “Delete”.
  • Dropdown triggers show the current value — “Last 7 days” with a trailing caret.
  • Icon-only buttons still have a label — it lives in aria-label and the tooltip.

Every exact value — heights, paddings, colour tokens per state, and the full API — is on the Specifications tab.
