Trends

Stable Last updated Oct 2026

Trends show how metrics change over time: an interactive line chart for exploring, and a KPI row with mini trends for headline numbers. The Specifications tab lists every value.

API and behavior

Designers put Trends-composition or Metric-trends-group in a Dashboard-widget slot and set the toggles.

<TrendsComposition
  periods={["MTD", "1M", "3M", "6M", "1Y", "custom"]}
  timeStep="weekly"
  download
  selection="checkboxes"
  metrics={[
    { key: "offtake", label: "Offtake", color: "pink" },
    { key: "share", label: "Est. Category Share", color: "purple" },
  ]}
  data={series}
/>

<MetricTrendsGroup>
  <MetricSummaryTrend metric="Offtake" value="₹57.4 Lacs" period="MTD"
    change={{ pct: 52.3, abs: "₹16.7 L" }} vs="Previous Period" trend={points} />
</MetricTrendsGroup>

Source

Values come from the Trends Documentation frames in the Cube Core Figma file (Anatomy, Property, Color Annotation, Dimensions, API, Usage Guidelines, How to use) and the live Trends-composition, Trends, Trend-metric-selector, X-Axis, Metric-trends-group, Metric-summary-trend and Accuracy Level components.

Where Figma disagrees with itself or has gaps: the Usage frame says “ten rules” but has nine. The metric card uses the old “Flat White” colour; this site uses Neutrals/White/100. The Accuracy Level chip is built on the deprecated Status chip and should move to Standard-chip; Figma has no Medium accuracy colour token, so this site uses an amber tint. Metric-and-data’s Use Case “Nivea” is a brand name, not a generic variant. The Wt. OSA% chip uses the Bronze palette while its line uses Green/600, so “chip colour = line colour” is only approximately true. Lines in the Figma chart are illustrative; this site draws them from sample data.
