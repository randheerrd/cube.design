Popup

Stable Last updated Oct 2026

A dialog that appears over a dimmed page and needs the user’s attention before they continue. A Task modal asks the user to do or decide something; a Message modal reports a state or result. The Specifications tab lists every value.

API and behavior

Designers: for a Task modal, start from a template or the task popup and fill the content slot; for a Message modal, pick the size, swap the illustration and edit the text. Developers: both are role="dialog" and aria-modal="true" over a scrim, centred and focus-trapped.

Source

Values come from the Popups — Documentation frames in the Cube Core Figma file (Anatomy, Property, Color Annotation, Dimensions, API, Usage Guidelines, How to use) and the live Popups components.

Where Figma disagrees with itself: the docs give the task title as SemiBold 16/18, but the component uses Bold 18/24 (used here). The “Yes, Delete” button in the template is blue in Figma, but the docs require a Destructive (red) button for delete (shown red here). The footer shadow is documented but switched off on the component. The docs recommend a 40% black scrim, while the in-context mocks use 20%. Component defaults are Destructive and Medium, while the API table lists Alert and Large. Illustrations are exported from the Custom popup graphics library.
