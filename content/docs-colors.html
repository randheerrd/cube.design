Color

Stable Last updated Sep 2026

Five groups — Semantic, Accent, Brand, Neutral and Platform — cover every color in the product, each an 11-step 50–950 scale. The Specifications tab lists every hex value and token name.

● Primary ● Success ● Error ● Warning

Four semantic states, each built the same way: a 100-shade background paired with a 700-shade (or darker) foreground for contrast — the pattern every semantic and accent color follows.

Overview

Every color in Cube belongs to one of five groups, each an 11-step scale from 50 (lightest tint) to 950 (near-black shade):

GroupScalesPurpose
SemanticPrimary, Success, Error, Warning, Primary Text, Secondary Text, DisabledUI states and text hierarchy — the tokens most components reach for.
AccentRed, Pink, Blue, Purple, Green, Bronze, Orange, Light BlueChart series, badges and tags where a semantic meaning doesn't apply.
BrandBrandThe GobbleCube brand color, from light tints to deep navy.
NeutralWhite, Black (opacity scales)Overlays, scrims, borders and subtle backgrounds — layered over any color.
PlatformBlinkit, Instamart, Zepto, FK Mins, Amazon, NykaaPartner-brand references for badges and chart legends, not for primary UI.

Brand

The official GobbleCube brand scale. Reach for the ringed 600 shade for anything that should read as "GobbleCube" specifically — a logo mark, an empty-state illustration, a marketing surface — not as a substitute for Primary in product UI.

Neutrals

White and black opacity scales, not hex colors — each step is the same white or black at 10% more alpha, so it layers transparently over whatever sits underneath. Used for overlays, scrim layers, borders and subtle backgrounds.

Usage

Reach for the token, not a hardcoded hex — the same values used to generate every swatch on this page:

import { SEMANTIC_PRIMARY, ACCENT_BLUE, BRAND, NEUTRAL_BLACK } from './atoms/colors';

// A token is a scale, indexed by shade
const primaryAction = SEMANTIC_PRIMARY[600];   // #006adc
const infoBadgeBg    = ACCENT_BLUE[100];       // #e6f2ff
const infoBadgeText  = ACCENT_BLUE[700];       // #1778cd
const scrimOverlay   = NEUTRAL_BLACK[50];      // rgba(0, 0, 0, 0.5)

The recurring pattern: a light shade (50–100) for a background, the base shade (500–600) for an icon or an active state, a dark shade (700–900) for text on that light background.

Accessibility & contrast

Do

  • Pair a light background shade (50–100) with a dark text shade (700–900) from the same scale — that combination is built to clear 4.5:1 contrast.
  • Pair meaning with a second signal — an icon, a label, an underline — never color alone, for a person with color-vision deficiency.
  • Use Primary Text / Secondary Text for reading text, not a raw Accent shade.

Don't

  • Set text in a mid-scale shade (300–500) on a white background — it reads soft and often fails contrast.
  • Use Error or Warning as the only indicator of a state — add the word "Error" or an icon too.
  • Invent a new hex value for "just this one case" — every color a screen needs already exists in one of these five groups.
