Tabs

Stable Last updated Oct 2026

Tabs split related content into sections on the same page, and only one shows at a time. Primary tabs pick the section; secondary tabs (the Segmented Control) pick how it is shown. The Specifications tab lists every value.

API and behavior

Designers: place Navigation/Primary-tabs, rename each Tab Item and set one to Selected. Developers: build it as an ARIA tablist, where each Tab Item is a tab that controls a tabpanel.

TopicRuleNotes
Semanticstablist / tab / tabpanelaria-selected on the active tab; aria-controls to its panel.
Keyboard← →, Home / End, Enter / SpaceArrows move focus; activate on Enter or automatically.
SelectionExactly one tab; the first by defaultKeep it in the URL (?tab=platforms).
Disabled tabNot focusableA tooltip explains why (Locked).
OverflowHorizontal scrollNever wrap to a second line.
Secondary tabsSeparate stateReset or keep per primary tab; decide per product.

Source

Values come from the Tabs — Documentation frames in the Cube Core Figma file (Anatomy, Property, Color Annotation, Dimensions, API, Usage Guidelines) and the live Tabs/Tab Item, Navigation/Primary-tabs and Selection/Segmented-control components. Figma has no “How to use” frame for Tabs, so the build steps here are written from the API notes.

Where Figma disagrees with itself (this site follows the component): the docs give the Indent padding as 12 for both sizes, but Large uses 16. The API lists Indent’s default as Yes; the component defaults to No. One Properties tile calls Medium the default Size; the API and component say Large. The Color doc says the prefix icon follows the label colour, but on Hovered and Selected it uses its own values (#5f717b and #23292e), and they are raw hex, not tokens. For the Segmented Control, the anatomy gives radius 8 and padding 2 (true only for the Primary type), the dimensions caption calls the Secondary Medium 32 tall (it is 28), and the API gives Size’s default as Medium (the component’s is Small) and leaves out Is Rounded. The live section calls the Tab Item add-ons “Secondary (Toggle) Properties” and the prefix “Left Icon”. There is no focus state.
