Bar chart

Compares amounts with bars. Bar chart/Vertical draws columns for values over time or a few categories; Bar chart/Horizontal draws ranked or compared rows. Both are built from the same bar, so colours and sizes stay consistent.

Cube Core

Figma
Guidelines Specifications Code (not in Storybook yet) Accessibility (coming soon)

At a glance

Use a bar chart when people need to compare amounts — month by month, city by city, brand by brand. There are two components: Bar chart/Vertical draws columns (Type Column, Stacked or Column + line) and Bar chart/Horizontal draws rows (Type Single, 100% stacked, Rating bands or Grouped). Pick the component and its Type, then size each bar to your data. Try every property below and hover a bar to read its value.

Use it for

Comparing amounts: a value per month, a ranking of cities or SKUs, what each total is made of, or your brand against competitors.

Pick the type

Vertical for time or a few categories; Horizontal for rankings, long labels and splits of 100%. Step 0 maps each need to a Type.

Key rule

Start the axis at 0, keep stacks to 5 or fewer, and give every colour a name in the legend.

The playground follows the live Figma components: the controls are the component’s own properties, in the order of the Figma panel — Type and Stacks first, then the switches. Turning on Show extra segments adds a Colour 6–8 segment to the first bar (Dec’25); the playground also adds its legend item, which you do by hand in Figma.

How it’s built

Two public components and two private building blocks. You only insert the public ones; select a bar inside them to reach _Bar and _Bar segment.

① Bar chart/Vertical

Columns over time or a few categories. Type Column, Stacked (Stacks 2–5) or Column + line. 790 × 268, with 12 bars by default.

② Bar chart/Horizontal

Ranked or compared rows. Type Single, 100% stacked (Stacks 2–5), Rating bands or Grouped. 560 wide, 3–5 rows.

③ Bars slot

Vertical only. Holds the _Bar columns: add or remove one per period, then resize each bar’s height to its value.

④ _Bar (private)

One bar. Orientation Vertical / Horizontal; Type Single (Stacks 1) or Stacked (Stacks 2–5). Stack colours follow the legend order.

⑤ Extra segments slot

On a stacked _Bar, Show extra segments opens a slot on top (vertical) / at the end (horizontal) for more than 5 stacks. The bar keeps its total size.

⑥ _Bar segment (private)

One stack segment, 24 × 24, Colour 1–8. Drop it into Extra segments and resize it to set its share.

Anatomy

Both charts sit on the same parts: bars built from _Bar, values written as plain text, and colours from local variables. The vertical chart adds axes, a grid and a legend; the horizontal chart is a list of label · bar · value rows.

_Bar and extra segments

_Bar is the private bar inside both charts: 24 × 160 vertical (radius 3 on top) or 240 × 12 horizontal (radius 4). On a stacked bar, Show extra segments opens a slot for a 6th, 7th or 8th stack — on top for vertical, at the end for horizontal. The bar keeps its total size, so the other segments get shorter.

Show extra segments = false

Stacks = 5, vertical and horizontal. The default.

Show extra segments = true

A Colour 6 segment (Light Blue/500) is added: 24 tall on top, or 40 wide at the end.

_Bar segment · Colour

Colours 1–5 are the stack colours (bottom → top / left → right); 6–8 are for extra stacks. Add a legend item with the same colour for every segment you add.

Colour 1 – 8

Primary/600 · Purple/400 · Pink/400 · Orange/400 · Green/600 · Light Blue/500 · Red/400 · Steel Blue/600.

Writing content

Everything you read on a bar chart is plain text in the layers — there are no text properties. Replace every placeholder with real data.

  • Chart title — on the Card or Dashboard widget, not on the chart: what is measured and when, e.g. “Ratings added · last 12 months”.
  • Y-axis ticks — 5 round steps from 0 with the unit on every tick: “0 lac · 0.3 lac · 0.6 lac · 0.9 lac · 1.2 lac”.
  • Period labels — one per bar, short month and year: “Dec’25”, “Jan’26”.
  • Axis titles — the measure in title case: “Ratings Added”, and “Avg Rating” on the right axis.
  • Legend names — short names people know: “Blinkit · Zepto · Instamart”. Never ship “Series 1”.
  • Row labels — the real name: “Delhi-NCR”, “Mangaldeep”. They truncate at 120px, so keep them short or abbreviate the same way on every row.
  • Row values — the number with its unit and the same decimals on every row: “84”, “93.5%”, “₹209”, “4.7”.
  • Grouped — the group label is the metric with its unit (“Avail in LS %”); tiers are always in the same order: My brand · Brands to chase · Leaders.

How to add one in Figma

Step-by-step for designers.

Step 0 · Which bar chart?

You want to show…Use
A value over time / a few categoriesVertical · Column
What each column is made ofVertical · Stacked (2–5)
Volume + a rate on its own scaleVertical · Column + line + Right axis
A ranking with long labelsHorizontal · Single
Parts of 100% per rowHorizontal · 100% stacked
Rating split per brandHorizontal · Rating bands
My brand vs competitors per metricHorizontal · Grouped
One total split into partsA pie chart, not a bar chart

Build a bar chart in 5 steps

  1. Insert and pick Type
    Assets → “Bar chart/Vertical” or “Bar chart/Horizontal”. Set Type (see Step 0), and Stacks for stacked charts.
  2. Set the bars
    Vertical: add / remove _Bar instances in the Bars slot for your periods, then resize each bar’s height. Horizontal: resize each bar’s width; use Row 4 / Row 5 for the row count.
  3. Edit axes and labels
    Ticks, month names, row labels and values are text — match them to your data. Turn on Right axis for a second measure.
  4. Extra stacks if needed
    Select a stacked bar → Show extra segments → add a _Bar segment (Colour 6–8) → add a legend item with the same colour.
  5. Finish
    Legend on for stacked and combo charts; grid on for reading values; place the chart in a Card or Dashboard widget.

Before you hand off

  • Right chart: Vertical for time / a few categories, Horizontal for rankings and splits.
  • Axis starts at 0; ticks and labels match the data.
  • Stacks ≤ 5; legend items match the stacks (including extra segments).
  • A second measure sits on the right axis.
  • Values visible on horizontal rows.
  • Bars sized to the real data.

Behavior & accessibility

TopicWhat to do
ScaleThe axis starts at 0 with 5 round ticks. Never truncate the baseline — it makes small differences look huge.
Hover a barShow a tooltip with period · series · value and dim the other bars. Stacked: one tooltip that sums up the whole column.
Sorting (Horizontal)Largest first, unless the order itself means something (5★ → 1★, or time).
OverflowMore than 12 columns → scroll sideways or aggregate (weeks → months).
Long labelsRow labels truncate at 120 with an ellipsis; show the full name in a tooltip.
Empty / loadingNo data → an Empty state. Loading → a Skeleton the same size as the chart.
