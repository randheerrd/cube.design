Divider

A divider (Divider/Separator in Figma) is a thin line that separates groups of content: list rows, header and body, inline items, summary and details. It comes horizontal or vertical, Solid or Dashed, in three emphasis levels. Always use the component instead of drawing lines, so every divider in the product looks the same. The Specifications tab lists every value.

At a glance

The simplest component in the system: a container that fills its parent and a 1px line. Use one when spacing alone doesn’t separate groups clearly. Prefer white space first; add a divider only when it helps scanning.

Three properties

type horizontal | vertical · Style Solid | Dashed · Emphasis Subtle | Default | Strong.

Pick the emphasis

Subtle for most cases (lists, dense UI), Default for cards and accordions, Strong for section breaks.

A container that fills its parent and a 1px “Line” drawn with a token-bound stroke — the top edge for horizontal, the left edge for vertical. Nothing else: no padding, no margin, no label.

Type

Property type: horizontal or vertical. Pick by how the groups sit — stacked or side by side.

horizontal Default

Between stacked groups. Fills the container width — set the instance to Fill container (it is 320 wide until you do).

vertical

Between side-by-side items. Fills the container height, or a fixed 16–28 in rows (it is 120 tall until you do).

Style

Property Style: Solid or Dashed. Both are 1px; Dashed is 4 on / 4 off.

Solid Default

A continuous line — list rows, cards, accordions and section breaks.

Dashed

Dashes of 4 on / 4 off. Use it to split a summary from its details, usually with Strong.

Emphasis

Property Emphasis: Subtle, Default or Strong. Each maps to one colour variable — no raw values.

Subtle

#E8EAEE · Secondary-text/100. List rows, header / footer edges, dense UI. Use it for most cases.

Default Default

#CAD2D7 · Primary-text/200. Accordion, cards, general separation.

Strong

#BFC5CF · Secondary-text/300. Section breaks, dashed summary / details split.

Common layouts

Use a divider when spacing alone doesn’t separate groups clearly: list rows, header vs body, inline items, summary vs details. Prefer white space first; add a divider only when it helps scanning. Use Subtle for most cases, Default for cards / accordions, Strong for section breaks.

How to add one in Figma

Add a divider in four steps.

  1. Insert it
    Assets → “Divider”. Place it inside the auto-layout, between the two groups.
  2. Pick type
    horizontal between stacked groups; vertical between side-by-side items (set its height to the row height, 16–28).
  3. Pick Style and Emphasis
    Subtle for lists / dense UI · Default for cards / accordions · Strong for section breaks. Dashed to split a summary from its details.
  4. Set it to Fill container
    Horizontal: width = Fill. Vertical: height = Fill (or a fixed 16–28 in rows). Spacing comes from the parent’s gap.

Before you hand off

  • Divider component used (no hand-drawn lines).
  • Fill container set.
  • Emphasis matches the context (Subtle by default in lists).
  • Spacing from the parent gap, not extra frames.
  • Dividers only where spacing isn’t enough.

Behavior & accessibility

A divider is static: it has no states and nothing to click. What matters is whether it means something to assistive technology.

TopicWhat to do
DecorativeWhen the line is purely visual, hide it from screen readers with aria-hidden="true".
Meaningful breakBetween groups in menus and toolbars, use role="separator" with aria-orientation (“horizontal” or “vertical”).
ElementRender a horizontal divider as <hr>, or any element with role="separator" and aria-orientation.
SizeHorizontal: width: 100%. Vertical: align-self: stretch, or a fixed 16–28 inside a row.
SpacingThe divider itself has no margin. Space comes from the parent layout’s gap.
ColourAlways the Emphasis token, never a raw value, so every divider updates together.
