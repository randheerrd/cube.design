Right Overlay

Stable Last updated Oct 2026

A panel that slides in from the right edge over the page, used for quick, contextual information — drill-downs, details and trends — without navigating away. Built from a Header (breadcrumb, heading, tabs, close), a flexible Body slot, and an optional Footer with actions.

Writing content

  • Breadcrumb — parent items first, the current item last: “Whole Wheat Atta › Delhi NCR”. Use the names people saw on the page they clicked.
  • Heading — the item name, not an action (“Whole Wheat Atta 5 kg”, not “View details”).
  • Description — one or two lines of context: scope, period, source. Long text belongs in the body.
  • Tabs — short nouns for views of the same item: Drilldown, Competition, My Trends.
  • Primary action — a verb for what happens: Export, Apply, Save. Not “OK” or “Close”.

Adding one to a screen

A step-by-step guide for designers: add a right overlay to a screen and fill it with content — without detaching it. Highlighted property values are the ones you change.

  1. Place it on the screen

    • Open Assets and search “Right overlay”.
    • Drop it into your screen frame, aligned to the right edge: X = frame width − 760, Y = 0.
    • Stretch the height to the full frame (e.g. 900). Keep the width 760.
    • Optional: add a scrim (Neutrals/Black/20) behind it if the page should dim.

    Width: 760 Height: Fill frame Position: Right edge

  2. Set the header

    • Select the nested Right-Overlay-Header.
    • Turn on what you need: Breadcrumb, Heading, Description, Tabs (keep at least Breadcrumb or Heading).
    • Edit the heading / description text directly.

    Show Breadcrumb: On Show Heading: On Show Description: On Show Tabs: On

  3. Set the breadcrumb depth

    • Select the Breadcrumb → choose L2 / L3 for 1, 2 or 3 levels.
    • Type the levels: parent items first, current item last (bold).

    L2: Yes L3: Yes

  4. Rename the tabs

    • Select each Tab Item inside the header tabs and change its Text.
    • Set the active one to Selected; hide unused tabs with the Tab 3…8 toggles on the tabs.

    Tab Item · Text: Drilldown Tab Item · State: Selected

  5. Fill the body

    • Click the Right-overlay-body slot → the “+” lets you insert content.
    • Preferred blocks: Segmented-control, Message, Table-template, Trends-composition.
    • Stack them vertically — the slot already has 20px padding and 16px gap.

    Right-overlay-body: Insert content

  6. Set the footer

    • Read-only content → Show Modal-Footer = false.
    • With actions → keep it on; in the Modal-Footer pick Primary (one), Secondary, Cancel and the bottom-left free slot.

    Show Modal-Footer: On / Off Primary Action: On Free Slot - Bottom left: On

  7. Prototype open / close

    • Trigger: On click of the row / chart point → Open overlay → Move in from right (250ms, ease-out).
    • Close button: Back / Close overlay. Esc should close too (note it for devs).

    Interaction: On click Animation: Move in · right Duration: 250ms

Before you hand off — checklist

  • It’s an instance of “Right overlay” (not detached).
  • 760 wide, full height, docked to the right edge.
  • Header has a breadcrumb or heading that names the item.
  • Active tab is Selected; unused tabs hidden.
  • Body content inserted in the slot (no content placed on top of the slot).
  • Footer only if there are actions — one Primary.
  • Annotate how it opens (trigger) and that Esc / the close button closes it.

Common questions

QuestionAnswer
My content isn’t in the preferred list.You can insert any component or frame into the slot. Keep the 20px padding (already in the slot) and use existing components.
Can the overlay be wider?Keep 760 for consistency. If content really needs more room (wide tables), consider a full page instead.
How do I show a loading or empty state?Put a loader or empty-state message in the body slot; keep the header and footer visible.
Can I open an overlay from inside an overlay?No — replace the content and update the breadcrumb instead of stacking panels.
Mobile / small screens?There is no mobile variant yet; note “full width on small screens” for developers.

Behavior & accessibility

TopicWhat to do
OpenSlides in from the right in 200–250ms (ease-out), triggered by a row or chart click.
CloseThe close button, Esc, Cancel, or a click on the page outside (optional). Return focus to the row or point that opened it.
ScrollOnly the body scrolls; the header and footer stay fixed.
Width760, fixed. Below 1024px viewports, use full width.
Focusrole="dialog" + aria-modal="true", labelled by the heading (or the current breadcrumb level). Move focus into the panel on open and trap it there.
Tabsrole="tablist"; ← / → move between tabs.
StackingOne overlay at a time. Opening another replaces the content and updates the breadcrumb.
