Divider

New Last updated Nov 2026

A divider (Divider/Separator in Figma) is a thin line that separates groups of content: list rows, header and body, inline items, summary and details. It comes horizontal or vertical, Solid or Dashed, in three emphasis levels. Always use the component instead of drawing lines, so every divider in the product looks the same. The Specifications tab lists every value.

Properties

Three variant properties — 2 × 2 × 3 = 12 variants. No text, boolean or slot properties.

PropertyValuesRequiredDefaultNotes
typehorizontal | verticalrequiredhorizontalOrientation. In code: orientation.
StyleSolid | DashedrequiredSolidDashed = 4 on / 4 off. In code: variant.
EmphasisSubtle | Default | StrongrequiredDefaultColour token. In code: emphasis.

API and behavior

Designers: insert Divider, set type / Style / Emphasis, and set the instance to Fill container. Developers: <Divider orientation="horizontal|vertical" variant="solid|dashed" emphasis="subtle|default|strong" /> → <hr> / role="separator" with aria-orientation.

// type → orientation · Style → variant · Emphasis → emphasis
<Divider orientation="horizontal" variant="solid"  emphasis="subtle" />   // list rows
<Divider orientation="vertical"   variant="solid"  emphasis="subtle" />   // inline items, 24 tall
<Divider orientation="horizontal" variant="dashed" emphasis="strong" />   // summary / details

/* Renders as <hr> (or role="separator" + aria-orientation). No margin. */
hr {
  border: 0;
  border-top: 1px solid #CAD2D7;   /* Emphasis token: Semantics/Primary-text/200 */
  width: 100%;
  margin: 0;
}
[role="separator"][aria-orientation="vertical"] {
  border-left: 1px solid #E8EAEE;  /* Semantics/Secondary-text/100 */
  align-self: stretch;
}
/* Dashed: border-style: dashed, or a 4 / 4 background pattern for exact dashes */

Source

Values come from the Divider — Documentation frames on the Divider/Separator page of the Cube Core Figma file (Anatomy, Property, Color Annotation, Dimensions, API, Usage Guidelines, How to use) and the live Divider component set in Divider · component (use this).

Where Figma leaves gaps. The Don’t · 04 example (“fixed-width divider in a wider container”) is clipped to 10px tall in Figma, so only part of “Section A” shows; this page draws the intended Section A / 120px divider / Section B. The inline-items example uses a 24-tall vertical divider while the in-context frame uses 28; both sit in the documented 16–28 range. Figma property names (type, Style, Emphasis) differ from the developer props (orientation, variant, emphasis); both are listed. Dashes are drawn here as an exact 4 / 4 pattern, as the API notes allow, because CSS dashed borders vary by browser.
