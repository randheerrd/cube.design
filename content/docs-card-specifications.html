Card

New Last updated Nov 2026

A bordered container for one item — a product, a group, an action, a KPI or an account. Every card has a header, a main value, optional supporting metrics and an optional footer action; eight types reuse the same building blocks, and one card per row is Selected.

API and behavior

Designers: insert Card, pick Type and State, fill Title / Label / Value, and toggle the parts you need. Developers: <Card type="productCompare|groupCompare|categorySummary|…" selected onSelect title label value delta={…} metrics={[{name,value,delta}]} image platform chips highlight footer={{label,onClick}} />.

<Card
  type="productCompare"          // productCompare | groupCompare | categorySummary | …
  selected                       // State = Selected — one card per row
  onSelect={select}              // click / Enter / Space; single selection in the row
  title="Nivia Stormwhite Rubber Football"
  value="₹1,502"
  delta={…}                      // ▲ 52.3% (₹52 L)
  metrics={[
    { name: "Wt. OSA %", value: "8.9%", delta: … },
    { name: "Wt. Discount %", value: "8.9%", delta: … },
    { name: "ASP", value: "8.9%", delta: … },
  ]}
  image={…}                      // alt = product name
  platform                       // platform button → platform breakdown
  chips={…}                      // “12 pcs”
  highlight={…}                  // Offtake Share 8.9% ▲ 52.3%
  footer={{ label: "Compare SKUs", onClick: openCompare }}   // doesn’t change the selection
/>

Source

Values come from the Card — Documentation frames on the Cards page of the Cube Core Figma file (Anatomy, Property, Color Annotation, Dimensions, API, Usage Guidelines, How to use), the live Card component set (8 types × State) in Card · component (use this), and the separate Card/Insight component.

Where Figma disagrees with itself or leaves gaps: Success/600 resolves to two values — #46a758 in Product compare, Category summary and Group compare (another library ⚠), #009966 in KPI (the Color page value); the KPI info icon and the pack chip label (#ed5f00, vs #f54900 on the Chips page) are also from another library. The anatomy calls the highlight strip “Primary/50”; the colour table and the component use Steel Blue/100 (Primary/50 only when Selected). There are two Selected styles: Primary/50 + Primary/300 (Action, KPI, Product list item, Segment summary) and the “approved” Primary/100 + Primary/400 (Product compare, Category summary, Group compare); the colour frame’s “Visual reference — older Selected style” shows one of each (Action and Product compare), so it doesn’t say which style is the older one. Selected variants change radius / padding / gap on three types (see Dimensions). The API table lists State as “Yes · Default | Selected (Account: No · Default)” — the Yes / No is left over from an older “Selectable” property the set no longer has. The Figma rows “Product comparison row” and “Group comparison row” use older “Selectable” and “Card/Group compare” instances and turn Show Highlight off on one card, against Don’t 02; the rows here keep the same toggles on every card. “₹1,5Cr” is kept as written in Figma. The behaviour table names hover as “raise shadow” without a value, so the replicas here don’t animate it; Card/Insight’s mini table overflows its cells in Figma and is laid out to fit here. Icons are Phosphor glyphs (shown with the Phosphor font); the SKU and Flipkart Minutes images are exported from Figma.
