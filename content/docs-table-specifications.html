API and behavior

Designers start from Table-template, fill the “Table columns” slot with Table-Columns, set each column’s content type, then edit the header text and values. In code a table takes column definitions and rows.

<Table
  toolbar={{ search: true, filter: true, download: true }}
  columns={[
    { type: "selection" },
    { type: "leading", header: "SKUs", content: "sku", sticky: true },
    { type: "display", header: "Offtake", content: "amount", align: "right", sortable: true, info: "…" },
    { type: "display-divided", header: "Blinkit", columns: [ … ] },
  ]}
  rows={rows}
  rowHeight={52}
  rowState={(row) => row.ownBrand ? "own-brand" : "default"}
  footer={{ pageSize: 10 }}
/>
TopicRuleNotes
SortingClick a sortable headerOne column at a time; show the direction.
SelectionHeader checkbox: none / all / someIntermediate when some rows are selected; selection summary in the footer.
HoverThe row highlights on hoverAll cells in the row use State = Hovered.
StickyHeader + leading columnKeep the identity visible while scrolling.
PaginationFooterRows per page + page buttons; reset to page 1 on filter.
Empty / loadingEmpty-state or skeleton rowsInside the table body.

Source

Values come from the Tables Documentation frames in the Cube Core Figma file (Anatomy, Property, Color Annotation, Dimensions, API, Usage Guidelines, How to use) and the live Table-template, Table-Column, Column-header, Table-cell, Table-supporting-elements and Table-footer-new components.

Where Figma disagrees with itself or has gaps: the Display cell component is named “Dispaly”. Amount content has six unnamed extra Appearance values (Appearance4–9). The Color doc gives De-emphasized the same colour and weight as Normal (Primary-text/950, SemiBold), so it doesn’t de-emphasise; this site uses Medium Secondary-text/700. Hovered and Highlighted use the same fill (Steel Blue/50). Error/Breach exists on Display cells only. The footer’s grey text is a raw #5F717B, not a token. The old “Table” component is replaced by Table-template. Figma has no focus states; this site shows a 2px Primary/600 ring on sort buttons.
