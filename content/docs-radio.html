Components

Radio

Stable Last updated Oct 2026

A radio lets people pick exactly one option from a small set. Use Radio-inline in forms and menus and Radio-chip for prominent choices. The Specifications tab lists every value.

Guidelines Specifications Code (not in Storybook yet) Accessibility (coming soon)

At a glance

A radio lets people pick exactly one option from a small set, with every option visible. Exactly one option is always selected.

Radio-inline

Control and label. The default for forms, settings and menus.

Radio-chip

A bordered option for prominent choices — views, plans, modes — with an optional description.

Not a radio

Several answers? Checkbox. On or off? Toggle. Eight or more options? Dropdown.

Default currency

Chart view

Try it: click an option or use the arrow keys. Selecting one clears the others in its group.

Which one do I use?

Radios are for one choice from 2–7 options that should all be visible.

SituationUse
One choice in a form or settings pageRadio-inline, Large, stacked
One choice in a dropdown menu or filter panelRadio-inline, Medium
A prominent choice, such as a plan or a modeRadio-chip, Large, with Description
Two or three views of the same dataRadio-chip with Selection control off, or a Segmented Control
Several options can be chosenCheckbox
A single on/off settingToggle or a Checkbox — never a single radio
Eight or more optionsDropdown

Anatomy

1 · Radio control

Selection-control/Radio: Selected, Size 16.

#ElementNotes
1ContainerA fixed 14 × 14 or 16 × 16 frame. It lines up with the first line of the label.
2RingA circle inset 1px. Unselected: a thin Secondary-text/700 ring. Selected: a thick Primary/600 ring (3.36 at 14, 3.92 at 16).
3CentreWhite when unselected; Secondary-text/50 on hover; Disabled/50 when disabled. When selected, the centre is knocked out and shows the surface behind.

2 · Radio-inline

Large, Selected, with the prefix icon, info and Pro on.

#ElementNotes
1ContainerNo fill or border; hugs its content. Gap 4 (Medium) or 6 (Large). The whole row is the click target.
2Radio controlSize 14 for Medium, 16 for Large. Its state follows the row.
3Prefix icon or platform logoOptional: Show Prefix Icon + Prefix Icon (default Cube), or Show Platform for a 20px logo.
4LabelThe Label property. Medium 12/16 or 14/18; SemiBold Primary-text/950 when selected.
5Info iconOptional Show Info ℹ️. Pair it with a tooltip that explains the option.
6Pro tagOptional Pro 💎 for a premium option.

3 · Radio-chip

Large, Selected, with Description, Recommended and Count on.

#ElementNotes
1Container28 or 32 tall (54 with a description), padding 8 or 10, radius 6 or 8, 1px inside border. Fill and border change with the state.
2Radio control14 or 16. Turn Selection control off for a button-like look.
3LabelMedium; SemiBold Primary/700 when selected.
4Recommended tagOptional Recommended (with a description only). Use it on one option at most.
5DescriptionDescription Yes (Large only): a second line, Regular 12/16, that explains the consequence.
6CountOptional Count: a number badge, such as how many items match.

4 · Disabled and locked

Radio-inline, Large, Disabled, with Pro and Locked on.

#ElementNotes
1Disabled controlDisabled/50 centre and a Disabled/400 ring (thick when selected).
2Disabled labelDisabled/400. Keep unavailable options visible so the set is complete.
3Pro tagShows the option needs a paid plan.
4Lock iconLocked 🔒, shown on disabled variants only. Add a tooltip with the reason or upgrade path.

Component family

Three components. Pick by context, then set State and Size.

Selection-control/Radio

The bare control. Custom layouts, tables, inside other components.

Radio-inline

Control and label. Forms, settings and menus — the default choice.

Radio-chip

A bordered option for prominent choices; an optional description.

Radio groups

Radios always come in groups of two or more with exactly one selected. Build groups with auto layout.

Inline, vertical list Default

The default. Stack Radio-inline 8px apart (Medium) or 12px (Large). Best for 2–7 options.

Chip, horizontal

Radio-chip in a row, 8px apart. Best for 2–5 short options.

Chip with descriptions

Large chips with Description for decisions that need context.

Common layouts

Radio-inline for forms and menus; Radio-chip for prominent or visual choices.

Do’s and don’ts

Five rules in three groups.

Selection

Do

Always pre-select one option. A radio group should never be empty.

Don’t

Don’t leave every option unselected. Once people pick, they can’t get back to “nothing”.

Do

Use a Checkbox or a Toggle for a single yes / no choice.

Don’t

Don’t use a single radio on its own. Once selected, it can’t be turned off.

Layout and labels

Do

Stack three or more options vertically so they are easy to scan.

Don’t

Don’t run many radios along one line. It’s hard to tell which label belongs to which control.

Do

Keep labels short, parallel and starting with the key word.

Don’t

Don’t write long or inconsistent labels. The differences get lost.

Emphasis

Do

Mark at most one option as Recommended.

Don’t

Don’t add Recommended to several options. It stops meaning anything.

Writing content

  • Labels — short, parallel and starting with the key word: “Daily”, “Weekly”, “Monthly”.
  • Group label — name the choice above the group (“Default currency”). Don’t repeat it in each option.
  • Order — a logical order (time, size) or most-used first. Pre-select the most common option.
  • Description — one line that explains the consequence of the choice.
  • Disabled options — keep them visible, with Locked or Pro and a tooltip that says why.

Behavior & accessibility

TopicWhat to do
SemanticsA native <input type="radio"> with one shared name, inside a fieldset with a legend (or role="radiogroup" with a label).
KeyboardTab moves into the group, to the selected option. Arrow keys move the selection; Space selects.
SelectionExactly one option, always. Pre-select the most common one.
Click targetThe whole row or chip, label included.
FocusFigma has no focus state. Show a 2px Primary/600 focus ring in code.
DisabledNot focusable. Explain why in a tooltip on the Locked icon.
HoverHover and Hovered are pointer feedback only; don’t set them in code.
