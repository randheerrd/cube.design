Selection Group

New Last updated Oct 2026

A ready-made group of options with a title. Think of it as a small bordered box: a group header (the question) and a list of radio or checkbox options (the answers). It saves building radio / checkbox groups by hand and keeps spacing consistent.

Guidelines Specifications Code (opens Storybook in a new tab) Accessibility (coming soon)

Container, header and list spacing for every layout. All values in px. Option sizes come from the Radio / Checkbox components (Medium).

Properties

Designers: pick the variant with the four properties, then edit the header and options inside the instance. Developers: this is a labelled group (fieldset + legend) of radios (Single select) or checkboxes (Multi select) — the variant only changes layout and option style, not behaviour.

Source

Taken from the Selection Group documentation in the Copy-of-GC-Design Figma file and the Selection/Selection-group component. Notes:

  • The Group header text property isn’t connected to the title layer — edit the nested Card Header instead.
  • Unselected chip labels differ: Checkbox-chip Secondary-text/700, Radio-chip Secondary-text/800.
  • The radio / checkbox controls are SVG assets in Figma, so their colours here are matched to Primary/600 (selected) and Secondary-text/400 (unselected outline).
  • Primary/600, Secondary-text/300 · /900 and Disabled/100 · /400 aren’t drawn in these frames; their hex values come from the other Cube docs.
  • In code the group maps to Storybook’s RadioGroup (Single select) and CheckboxGroup (Multi select).
