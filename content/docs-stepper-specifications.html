Components

Stepper

Shows where the user is in a multi-step process — which steps are done, which is current and what’s next. Two layouts: Stepper-Horizontal (a compact progress bar for short flows) and Stepper-Vertical (a side list with descriptions for longer setup flows). Both are built from Stepper-elements, each with a Stepper-indicator (the circle).

Properties

Designers: place Stepper-Horizontal or Stepper-Vertical, turn steps on or off, then set each nested step’s Stage and edit its name. Developers: render from a steps array + current-step index — stages are derived (before = Completed, current = Selected, after = Upcoming), with Awaiting / Locked coming from data.

Source

Taken from the Stepper documentation in the Copy-of-GC-Design Figma file and the Stepper library page. Differences from Figma:

  • “Show connecter” is on for every step by default, so the anatomy mock-up of Stepper-Vertical still draws a line under the last step. Here the last step never has a connector.
  • Disabled/200 (the Locked connector) has no rendered example in Figma; it’s #E1E1E1 from the component.
  • The property is spelled “connecter” in Figma; it’s kept as-is in the property tables.
  • The real screens in the library (CPPT Setup, Portal Integrations) use “Previous” and “Back” for the same action — pick one.

The code equivalent in Storybook is Components / Stepper.
