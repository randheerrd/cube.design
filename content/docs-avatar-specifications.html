Avatar

New Last updated Nov 2026

An avatar is a small picture that stands for a person, brand, platform or workspace: a photo or logo, initials, or a placeholder. Circles are for people and rounded squares for brands and platforms; Avatar/group stacks several to show who is involved. The Specifications tab lists every value.

API and behavior

Designers: insert Avatar/single, pick Size and Roundness, then select the nested _Avatar-base to choose image / initials / Placeholder. Developers: <Avatar size shape="circle|square" src name fallback="initials|placeholder" /> — show the image, fall back to initials from the name, then to the placeholder.

// A user with no photo: circle, initials from the name (RS)
<Avatar size={32} shape="circle" name="Riya Sharma" fallback="initials" />

// A platform logo: square, image; the Placeholder if it fails to load
<Avatar size={24} shape="square" src={platform.logo}
        name="Flipkart Minutes" fallback="placeholder" />

// Initials: first letters of the first + last name, max 2, uppercase
const initials = (name) => {
  const w = name.trim().split(/\s+/);
  return (w[0][0] + (w.length > 1 ? w[w.length - 1][0] : "")).toUpperCase();
};

// Decorative when the name is next to it; a group is labelled as a whole
<img src={user.photo} alt="" /> Riya Sharma
<div role="img" aria-label="6 people: Riya Sharma, …">…</div>

Source

Values come from the Avatar — Documentation frames on the Avatar page of the Cube Core Figma file (Anatomy, Property, Color Annotation, Dimensions, API, Usage Guidelines, How to use) and the live Avatar/single, Avatar/group and _Avatar-base components in Avatar · components (use these).

Where Figma disagrees with itself or leaves gaps: the Dimensions and API frames describe Roundness = No as “radius 6” (“square r6”), but the components use 6 at 36–32, 4 at 28–20 and 2 at 16–12; the component values are used here. Every initials avatar in Figma is the same outlined “RK” glyph, including next to “Riya Sharma”; examples with a name use that name’s initials (RS), per the API rule. The initials glyph and the Building icon don’t scale with the avatar, so they are clipped at 16 and 12, as in Figma. The Do “Keep groups short (4–5) with a +N” is illustrated with the fixed group of 6 and no “+N” — there is no “+N” avatar yet — so it is drawn the same way here. The placeholder icon is listed as “Steel Blue tint”; its fill is #515f69. The usage illustrations are drawn at 2× in Figma (the 12px group at 4×); they are enlarged here too, less on narrow screens.
