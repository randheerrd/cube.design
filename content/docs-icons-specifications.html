Icons

Stable Last updated Oct 2026

Cube uses Phosphor Icons in three weights, through one Icon component that takes its size, weight and colour from tokens. The library lists every icon.

Guidelines Specifications Code (not in Storybook yet) Accessibility (coming soon)

Tokens

Size

TokenValueUse
xs12Chips, badges, tooltip text
sm14Medium components, 12px labels
md16Default; Large components, 14px text
lg20Side nav, page headers
xl24Section headers, large targets
2xl32Feature and empty states

Weight

TokenPhosphor weightUse
regularregularDefault
boldboldEmphasis
fillfillActive and selected
// tokens/icon.ts
export const iconSize = { xs: 12, sm: 14, md: 16, lg: 20, xl: 24, "2xl": 32 } as const;
export type IconSize = keyof typeof iconSize;
export type IconWeight = "regular" | "bold" | "fill";

Install

npm i @phosphor-icons/react
# optional — raw SVGs and metadata for docs, search and sprites
npm i @phosphor-icons/core

Don’t use the old phosphor-react package; it is deprecated and gets no new icons. Icons are exported in PascalCase with an Icon suffix (HeartIcon); the unsuffixed names are deprecated.

Icon component

Every icon goes through Cube’s Icon, which maps tokens to Phosphor props and sets accessibility.

// components/Icon/Icon.tsx
import type { Icon as PhosphorIcon } from "@phosphor-icons/react";
import { iconSize, type IconSize, type IconWeight } from "@/tokens/icon";

export interface IconProps extends Omit<React.SVGProps<SVGSVGElement>, "ref" | "color"> {
  icon: PhosphorIcon;          // e.g. TrashIcon
  size?: IconSize;             // default "md" (16)
  weight?: IconWeight;         // default "regular"
  color?: string;              // default currentColor
  label?: string;              // omit for decorative icons
  mirrored?: boolean;
}

export function Icon({ icon: Glyph, size = "md", weight = "regular",
                       color = "currentColor", label, ...rest }: IconProps) {
  return (
    <Glyph size={iconSize[size]} weight={weight} color={color}
      aria-hidden={label ? undefined : true} aria-label={label}
      role={label ? "img" : undefined} focusable="false" {...rest} />
  );
}

Setup

Global defaults

import { IconContext } from "@phosphor-icons/react";

<IconContext.Provider value={{ size: 16, weight: "regular", color: "currentColor" }}>
  <App />
</IconContext.Provider>

Server components

Import from @phosphor-icons/react/ssr. SSR icons don’t read IconContext, so pass props explicitly or go through the wrapper.

Bundle size

Named imports only — never import * as Icons. In Next.js 13+, add "@phosphor-icons/react" to experimental.optimizePackageImports.

Lint guard

// .eslintrc — block direct imports outside components/Icon/**
"no-restricted-imports": ["error", { "paths": [{
  "name": "@phosphor-icons/react",
  "message": "Import icons from '@/components/Icon' instead." }] }]

Without React

Plain HTML pages (like this site) use the icon font. Class ph is Regular, ph-bold Bold, ph-fill Fill.

<script src="https://unpkg.com/@phosphor-icons/web"></script>
<i class="ph ph-trash"></i>
<i class="ph-bold ph-trash"></i>
<i class="ph-fill ph-trash"></i>

Raw SVGs for sprites or other frameworks live in @phosphor-icons/core/assets/<weight>/.

Source

Phosphor Icons 2.1 (MIT) — phosphoricons.com, GitHub. The gallery reads @phosphor-icons/core metadata; this site vendors the Regular, Bold and Fill fonts from @phosphor-icons/web.

Differences from the Phosphor integration guide: the size scale adds 14 and uses 16 as the default (the guide suggests 12 / 16 / 20 / 24 / 32 with 20 as default), because Cube’s components are built on 14 and 16. This docs site is static HTML, so the React wrapper, registry, lint rule and Storybook stories are documented here for the product codebase rather than added to this repo.
