Tabs

Stable Last updated Oct 2026

Tabs split related content into sections on the same page, and only one shows at a time. Primary tabs pick the section; secondary tabs (the Segmented Control) pick how it is shown. The Specifications tab lists every value.

Guidelines Specifications Code (not in Storybook yet) Accessibility (coming soon)

At a glance

Tabs split related content into sections on the same page, and only one section shows at a time. There are two levels: primary tabs pick the section, and secondary tabs pick how that section is shown.

Primary tabs

Underlined text tabs at the top of a page or a large card. They switch between different sections: Overview, Platforms, SKUs.

Secondary tabs

The Segmented Control, placed inside a section. It switches between views of the same data: Chart or Table, Daily or Weekly.

Not tabs

Filtering by platform or brand? Use Selections or a Dropdown. Moving between pages? Use the Side Nav.

Try it: click a tab or use the arrow keys, then switch between Chart and Table.

Which one do I use?

Ask what changes when the user clicks it.

SituationUse
Sections of a report page: Overview, Platforms, CategoriesPrimary tabs, Large
Two to four sections inside a card or a panelPrimary tabs, Medium, Width Fixed or Fill
The same data shown another way: Chart or TableSecondary tabs (Segmented Control), Secondary type
A time grain inside a chart header: Daily, Weekly, MonthlySecondary tabs, Small
Filtering the data: platforms, brands, citiesSelections or a Dropdown, not tabs
Moving to a different page of the productSide Nav

How to build one in Figma

  1. Place the tab bar
    In Assets, insert “Navigation/Primary-tabs”. Large for a page, Medium for a card or panel.
  2. Set the count and width
    Turn Tab 3 to Tab 8 on or off for two to six tabs. Use Width Fixed or Fill inside cards and resize the bar to the card.
  3. Name the tabs
    Rename each Tab Item with a one- or two-word noun: Overview, Platforms, SKUs.
  4. Select one tab
    Set exactly one Tab Item to State Selected, usually the first.
  5. Add secondary tabs if needed
    Inside the section, add a Segmented Control (Type Secondary) to switch views of the same data.

Before you hand off

  • Tabs switch sections, not filters.
  • Two to six tabs, with short labels that don’t wrap.
  • Exactly one tab is selected.
  • The bar Size matches each Tab Item Size.
  • Disabled tabs keep the lock and have a tooltip.
  • No second row of primary tabs; use secondary tabs instead.

Writing content

  • Labels — one or two words, nouns that name the section: “Overview”, “Platforms”, “SKUs”.
  • Case — sentence case. No full stops and no icons unless every tab has one.
  • Order — the most-used section first; it is selected by default.
  • Secondary tabs — name the view, not the data: “Chart”, “Table”, “Weekly”.

Behavior & accessibility

TopicWhat to do
Semanticsrole="tablist", role="tab" and role="tabpanel". Set aria-selected on the active tab and aria-controls to its panel.
KeyboardArrow keys move focus between tabs; Home and End jump to the first and last. Enter or Space activates (or activate on focus).
FocusFigma has no focus state. Add a visible focus ring in code.
SelectionExactly one tab, the first by default. Keep the active tab in the URL (?tab=platforms) so links and refresh keep it.
DisabledNot focusable. A tooltip explains why it is locked.
OverflowScroll the bar sideways. Never wrap tabs onto a second line.
Secondary tabsTheir state is separate from the primary tab. Decide per product whether it resets or is kept when the primary tab changes.
