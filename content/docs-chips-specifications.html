Chips, Tags & Legends

Stable Last updated Oct 2026

Small coloured labels that sit next to data. Chips label a value or category, Tags show a key → value pair, and Legends name a chart series. Use a Sementic preset whenever one exists for your data; otherwise configure a Standard one.

Guidelines Specifications Code (not in Storybook yet) Accessibility (coming soon)

Color tokens

Read from the variants. Pattern: background = Color/100, border = Color/200, text = Color/600–900 (darker steps for light hues like Yellow and Light Blue). Names drop the shared Accent/ prefix (so Pink/100 is Accent/Pink/100); the token name is the contract.

Properties

Designers: use a Sementic component when one exists for your data; otherwise configure a Standard one. Developers: build one Chip primitive (type, color, size, rounded, iconOnly, prefix, suffix, label) and define Sementic presets as a config map { useCase → color, icon, size } on top of it.

Behaviour rules (for developers)

TopicValueNotes
Widthhug content · max-widthTruncate long labels with ellipsis + tooltip; never wrap.
Presetsconfig mapSame data type → same chip everywhere.
Interactive chipshover / focus states⚠ No hover / selected states in the component — use Selection chips (Checkbox-chip / Radio-chip) for selectable filters.
Removable tagssuffix × → removeUse when tags represent applied filters.
Legendsoptional click → toggle seriesIf clickable, add a “hidden” state (50% opacity).
Accessibilitylabel + aria for icon-onlyDon’t rely on colour alone — keep the text.
