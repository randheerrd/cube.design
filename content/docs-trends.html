Trends

Stable Last updated Oct 2026

Trends show how metrics change over time: an interactive line chart for exploring, and a KPI row with mini trends for headline numbers. The Specifications tab lists every value.

Guidelines Specifications Code (not in Storybook yet) Accessibility (coming soon)

At a glance

Trends show how metrics change over time. There are two families: an interactive line chart for exploring, and a compact KPI row for headline numbers.

Trends-composition

The interactive line chart: pick a period, pick metrics, read values.

Metric-trends-group

A row of 2–4 KPI cards, each with change and a mini trend.

Where they live

Both sit inside a Dashboard widget.

Time Step: Weekly

Try it: tick metric chips to show or hide lines, hover the chart to read every selected value for that month, and switch the period tabs.

How trends are built

Build each family from the outside in.

A · Trends-composition

The interactive line chart people explore: pick a period, pick metrics, read values.

  1. Trends-composition — controls + chart
  2. Trends — the chart card (Selection × Container)
  3. Trend-metric-selector · Y-axis · Trend-line · X-Axis
B · Metric-trends-group

The compact KPI row with mini trends, for headline numbers.

  1. Metric-trends-group — 2, 3 or 4 cards
  2. Metric-summary-trend — one card
  3. Metric and data · Trend-area · Accuracy Level

Do’s and don’ts

Nine rules in five groups.

Choosing

Do

Jan’26Feb’26Mar’26Apr’26May’26Jun’26
Est. Category Share48.5%for MTD−10.3% (−4.95%)vs Previous Period
Jan’26Feb’26Mar’26Apr’26May’26Jun’26

Use Metric-trends-group for 2–4 headline KPIs. People get the answer at a glance.

Don’t

Don’t use a full trend chart for each KPI. The page becomes a wall of charts.

Do

Time Step: Weekly

Use Trends-composition when people need to explore periods and metrics. The controls make it easy.

Don’t

Don’t remove every control from an exploration chart. People can’t change what they see.

Metric selection

Do

Use Check-boxes to compare 2–4 lines. A few lines stay readable.

Don’t

Don’t plot 8 or more lines at once. Lines overlap and the colours stop meaning anything.

Do

Metric: Offtake

Use Dropdown when there are many metrics but one is shown at a time. It saves space.

Don’t

Don’t show 15 chips in one row. The selector overflows and is hard to scan.

Time

Do

Time Step: Weekly

Match the Time-step and X-Axis: Daily for 1M, Weekly for 3–6M, Monthly for 1Y.

Don’t

Don’t show daily points over a year. 365 points make a noisy, unreadable line.

Add a disclaimer when data covers only some platforms. It prevents wrong totals.

Don’t present partial data as complete. People compare unlike numbers.

Writing content

  • Metric names — the short name people know: “Offtake”, “Wt. OSA%”, “Est. Category Share”. Explain it with the info icon.
  • Period — “for MTD”, “for L7D”. Always show one.
  • Comparison — name it: “vs Previous Period”, “vs Last Year”.
  • Values — short, with units: “₹57.4 Lacs”, “48.5%”, “4.3 Cr”.
  • Disclaimers — one short italic line: “for available platforms only”.

How to add one in Figma

A · Add a trend chart

  1. Insert it in a widget
    Add a Dashboard-widget and insert Trends-composition into its slot.
  2. Set the controls
    Date Range (period tabs) and Time-step on for exploration; Download Button if people export. Dual metric selection when there are metric families.
  3. Pick the selection type
    Select the nested Trends → Selection: Check-boxes (compare 2–4), Radio (one) or Dropdown (many metrics).
  4. Name the metrics and lines
    Rename the metric chips and keep chip colour = line colour. Set the X-Axis Time Stamp to match the time step.

B · Add a KPI row

  1. Insert the group
    Add Metric-trends-group, usually in an “Overview” widget. Count = 2, 3 or 4.
  2. Fill each card
    Metric, Value, the “for” period and the “vs” comparison. Set the change ▲ / ▼ value.
  3. Add data-quality signals
    Show Accuracy Level when data is estimated; Show Disclaimer for partial coverage; Show Cat. Chip for brand or category scope.

Before you hand off

  • The right component: the KPI row for headlines, Trends-composition for exploration.
  • Inside a Dashboard-widget.
  • The selection type matches the number of metrics.
  • The time step and X-Axis match the period.
  • Chip colours match line colours; four lines at most at once.
  • Every KPI has a period and a comparison.
  • Accuracy or a disclaimer is shown when data is estimated or partial.

Behavior & accessibility

TopicWhat to do
HoverA tooltip with every selected value for that date, and dots on each line.
Metric chipsToggle lines on and off. Chip colour = line colour.
Period and time stepRe-fetch and redraw. The X-Axis labels follow the time step.
EmptyAn Empty state in the plot area.
ChangeGreen ▲ up, red ▼ down, neutral for 0. Respect “lower is better” metrics, such as DOI.
ColourNever the only signal: chips show names and tooltips show values.
Chart alternativeOffer a data table or download. Give the chart an accessible name (role="img" + label).
KeyboardChips, period tabs and the download button are focusable controls.
