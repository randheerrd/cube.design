Components

Checkbox

Lets people pick zero, one or many options from a set. The family has five components: the bare Check-box control (+ accent colours), Checkbox-inline (control + label, for lists) and Checkbox-chip (bordered chip, for filter bars) (+ accent colours).

Source

Taken from the Checkbox documentation in the Copy-of-GC-Design Figma file (Anatomy, Properties, Color and Dimensions frames) and the checkbox library page. Notes:

  • Usage and API frames are Button content. In Figma, “Checkbox Usage Guidelines” and “Checkbox API” are copies of the Button pages (only the title says Checkbox). The When to use, Common layouts, Do’s and don’ts, Writing content and Configuration examples sections here were written for this page from the checkbox anatomy and property notes — please review them. The property tables come from the library component sets.
  • Hover inside inline / chip. The bare Check-box’s Hovered state has a Secondary-text/50 fill; inside Checkbox-inline and Checkbox-chip the hovered control has the darker outline but no fill. These pages follow that.
  • Intermediate glyph is a hard-coded #FFFFFF instead of Neutrals/White/100 (Figma flags this itself). The state is named “Intermediate”; the standard term is indeterminate.
  • Disabled add-ons. The Pro tag keeps its full-colour gradient and the info icon turns #69778B (not Disabled/400) on disabled variants, although the copy says disabled “greys out every element”.
  • Selected · Disabled label weight. It is SemiBold at Large but Medium at Medium in the library; these pages use Medium for both.
  • Yellow breaks the accent pattern: Warning/900 selected label, Warning/700 disabled label, Warning/400 disabled box (others use /700, /400, /300). Light Blue and Green use /700 for the box. “Bronze Green” is a teal.
  • Chip add-ons say “same slots as inline” but don’t show Locked; the library has it on disabled chips. The chip’s disabled border is Disabled/100 in the table but Disabled/200 in one description.
  • Colour legend mocks show a pink dot on a blue chip — in real use the dot matches the chart series.
  • Platform logos use the brand images already in this site (Flipkart, Amazon Fresh, JioMart); Figma uses Blinkit. Icons are redrawn equivalents of the Figma Cube, Info, Lock and Pro-gem assets.
  • In code: Storybook’s Controls/Checkbox and CheckboxGroup.
