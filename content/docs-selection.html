Selection Group

New Last updated Oct 2026

A ready-made group of options with a title. Think of it as a small bordered box: a group header (the question) and a list of radio or checkbox options (the answers). It saves building radio / checkbox groups by hand and keeps spacing consistent.

Guidelines Specifications Code (opens Storybook in a new tab) Accessibility (coming soon)

At a glance

Try it: pick a platform and a period (one each), then tick any categories. These are real radio and checkbox groups — Tab into a group, then use the arrow keys or Space.

Platform
Period
Category

Single select · Chip in a toolbar, and Multi select · Inline · Vertical in a panel.

1 · Header

The question or category name: “Platform”, “Category”.

2 · Options

The answers — radios (Single select) or checkboxes (Multi select).

3 · Box

A bordered container that keeps spacing and alignment consistent.

How to choose a variant

Selection-group has only four properties. Answer these four questions in order and you have the right variant.

① Type — can people pick more than one?

No → Single select (radios). Yes → Multi select (checkboxes).

Platform

Single select

One answer. Uses Radio-chip / Radio-inline.

Platform

Multi select Default

Any number of answers. Uses Checkbox-chip / Checkbox-inline.

② Element — how prominent should the options be?

Chip → bordered, button-like options (filter bars, few options). Inline → a plain control + label (forms, long lists).

Platform

Chip Default

Bordered, button-like. Good in toolbars.

Platform

Inline

Control + label. Good in forms and panels.

③ Layout Direction — where does the header go?

→ Horizontal: header on the left, options in a row (toolbars, compact rows). ↓ Vertical: header on top, options below (panels, forms).

Platform

→ Horizontal Default

Header on the left, options in a row.

Platform

↓ Vertical

Header on top, options stacked below.

④ Wrap ↩ — do the options fit on one line?

No → one row or column; the width hugs the content. Yes → a fixed width; options flow onto more rows.

Category

Wrap = No Default

One row — the width hugs the options.

Category

Wrap = Yes

A fixed width (530 here); options flow onto a second row, aligned under the options — not under the header.

Common layouts

Use a Selection-group whenever you show a set of radios or checkboxes with a title — filters, settings, forms. Toolbars → Horizontal + Chip. Side panels / forms → Vertical + Inline. Many short options in a fixed space → Wrap = Yes. For 10+ options use a Dropdown instead.

Do’s and don’ts

Do

Platform

Rename the header and options, and hide the options you don’t need.

Don’t

Group Header

Don’t ship placeholder text (“Group Header”, “Radio Label”) or unused options.

Do

Period

In Single select, pre-select one option.

Don’t

Period

Don’t leave a single-select group with nothing selected.

Do

Category

Use Wrap = Yes when options don’t fit on one line.

Don’t

Category

Don’t let a no-wrap row run off the screen or card.

Do

Category

Use Vertical for long lists (5+ options) in panels.

Don’t

Category

Don’t line up many inline options horizontally — hard to scan.

Do

Sort by

Use Single select for mutually exclusive options.

Don’t

Sort by

Don’t use checkboxes for mutually exclusive options — you can’t sort by two things at once.

Writing content

  • Header — the question or category as a short noun: “Platform”, “Category”, “Sort by”. Never leave “Group Header”.
  • Options — 1–3 words, parallel in form (all nouns or all periods), sentence case.
  • Order — most common first, or a natural order (Daily → Weekly → Monthly).
  • How many — 2–6 options. For 10+ use a Dropdown.

Behavior & accessibility

TopicWhat to do
Single selectExactly one option is selected — pre-select a sensible default. Clicking another option moves the selection.
Multi selectZero or more options. Each click toggles one option.
SemanticsRadio groups use role="radiogroup" (or a <fieldset> + <legend>), labelled by the header. Checkbox groups use role="group".
KeyboardTab moves into the group; arrow keys move between radios; Space toggles a checkbox.
Hit areaThe whole chip or label is clickable, not just the 14px control.
ApplyIn filters, apply on change; in forms, submit with the form’s button.
