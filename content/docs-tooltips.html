Overview

A tooltip answers "what is this value" for a single mark on a chart, a row in a table, a slice of a pie, or a region on a map — without a person having to leave the dashboard they are reading. It comes in two families:

TooltipPurpose
Standard TooltipA short line (or two) of plain text. Labels an icon, explains a flag, or spells out an abbreviation — the same job a conventional tooltip does anywhere else in software.
Standard Trendline TooltipA dark card built from three components — header, table and footer — that carries real numbers: a value, a comparison period, and a delta.

Seven examples cover the recurring dashboard cases so a designer never assembles a data tooltip from scratch: Platform-Trendline, Metric-summary-Trendline, SLA-Trendline, SLA-Pie-chart, RCA, RCA-Discount-deepdive and Geo-Intelligence. Each one is just the Trendline tooltip's own header, table and footer components configured for that case — not a component in its own right. See Examples for what each is for.

When to use

Use a Standard Tooltip to label an icon-only control or clarify a term. Use a Standard Trendline Tooltip — plain, or arranged as one of the examples below — whenever a chart, table or map needs to surface the exact number, comparison period and change behind a mark that is otherwise only shown visually — a bar's height, a pie slice's angle, a map region's shading.

When not to use

Do not use a tooltip as the only place a number lives — the underlying value should also be reachable without hovering (a legend, an export, a detail view) for anyone on touch or with a screen reader. Do not use a Standard Tooltip where a number, delta or table belongs; reach for a Trendline Tooltip instead so the value is legible on its own, not folded into a sentence.

Standard Tooltip

A single line of plain text by default. It can grow an icon, a header and an action button, and can switch from a fit-content single line to a fixed 240px width that wraps.

Standard Trendline Tooltip

Built from three components: a header naming the metric's period, a table of one or more rows, and a footer for context or a next step. Every example in the next section is these same three components, configured differently — none of them add a fourth.

Components

ComponentRole
Tooltip-headerA bold title (the comparison date) plus a muted sub-text (the comparison period, e.g. "vs Last month"). Either can be turned off.
Tooltip-table-cellHeader or Cell, aligned left or right. A cell can carry a color legend dot, a primary value, and a delta — each independently toggled.
Tooltip-footerMuted info text on the left, an optional action button on the right.

The legend dot always matches that row's series color on the chart it annotates. A delta is set in success green for a positive change and error red for a negative one — never color alone without the leading + or − sign, so the reading survives color blindness and grayscale printing.

Content

Numbers

Values follow the Indian numbering convention already used across the product's dashboards: Lakh (L) and Crore (Cr) rather than raw digits or thousands/millions — "3.2 Cr", not "32,000,000". Percentages carry one decimal place.

Deltas

A delta always leads with an explicit + or − sign before the number, in success green for a gain and error red for a loss — the sign carries the meaning, the color reinforces it. Never color the number without the sign, and never the reverse.

Header

The header's title is the point in time the row's numbers describe (a date or a month); the sub-text is the comparison period ("vs Last Day", "vs Last Month"). Keep both short enough to sit on one line without wrapping.

Footer

Footer info text is a short, italicized note — a data-freshness caveat, a caption — never a second data point. A footer button is a single clear next step ("View details", "View SKU"), not a second action competing for attention.

Universal behaviors

States

  • Hidden — default. Nothing is rendered until the anchor mark, row or region is hovered or focused.
  • Visible — shown immediately on hover, positioned near the pointer so it never covers the mark it is describing.
  • Dismissed — hides the instant the pointer leaves the anchor, or on Esc.

Interactions

All tooltips on this page open on hover of their anchor. A Standard Tooltip may also open on keyboard focus, the same as any conventional tooltip.

The action button and "Click to expand" are a real accessibility trade-off, not an oversight. A true role="tooltip" must never contain interactive content — nothing inside it can be focused or clicked, per WCAG 1.4.13. The moment a tooltip carries a "Button" or a "Click to expand" link, it is functioning as a small hover-triggered panel, not a tooltip in the strict ARIA sense, and needs its own keyboard and touch path: the same action must also be reachable by focusing and activating the anchor directly (e.g. Enter opens the same drill-down a click would), never left reachable only by a mouse hover.

Modifiers

Width

A Standard Tooltip is fit-content by default and switches to a fixed 240px once its text needs to wrap. The Trendline Tooltip and every example built from it size to their table's content — width is not set explicitly.

Header / footer

On the trendline family, header and footer are each independently optional — a single-row tooltip like SLA-Pie-chart carries neither.

Alignment

A table-cell is set to Header or Cell, and to left or right alignment, independently per column — labels read left-aligned, numbers read right-aligned so the digits line up down the column.
