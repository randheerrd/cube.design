Bar chart

Compares amounts with bars. Bar chart/Vertical draws columns for values over time or a few categories; Bar chart/Horizontal draws ranked or compared rows. Both are built from the same bar, so colours and sizes stay consistent.

API and behavior

Designers: use Vertical for values over time or categories (columns) and Horizontal for ranked rows and splits. Set Type and Stacks, resize the bars to the data, and add / remove columns in the Bars slot. Developers: <BarChart orientation="vertical|horizontal" type="column|stacked|combo|single|stacked100|rating" stacks={1–5} series={[…]} line={…} rightAxis legend grid />.

<BarChart
  orientation="vertical"          // vertical | horizontal
  type="combo"                    // column | stacked | combo — single | stacked100 | rating
  categories={months}             // ["Dec’25", "Jan’26", …] — one bar each
  series={[{ name: "Ratings Added", data: ratingsAdded }]}  // stacked: one entry per stack (max 5)
  line={{ name: "Avg Rating", data: avgRating }}           // combo, or showLine on column / stacked
  rightAxis                       // the line gets its own 0–5 scale
  legend grid axisTitles          // all on by default
  aria-label="Ratings peaked in Dec’25 at 1.05 lac"
/>

<BarChart
  orientation="horizontal"
  type="single"
  rows={[{ label: "Delhi-NCR", value: 84 }, …]}          // 3–5 rows, largest first
  showLabel showValue showTrack
/>

Source

Values come from the Bar chart — Documentation frames on the “Bar Charts” page of the Cube Core Figma file (Anatomy, Property, Color Annotation, Dimensions, API, Usage Guidelines, How to use) and from the live component sets Bar chart/Vertical, Bar chart/Horizontal, _Bar and _Bar segment. Where they disagree, these pages follow the live components.

Where Figma disagrees with itself or leaves gaps: the line series is Accent/Pink/600 (#e60076) in the live components, but the Anatomy frame calls it “Purple/600” and the Color Annotation “Accent/Purple/600”; both also say “line with points”, but the live line has no point markers. The Dimensions frame gives the vertical chart as “≈ 870 × 290”; the live component is 790 × 268 (840 wide with Right axis). The live Column and Stacked variants have a Show line boolean (default false) that the API frame and the Property frame don’t list. The API frame lists Show legend / grid / axis titles / Right axis for every vertical Type, and 100% stacked wires none of the horizontal toggles (always 4 labelled rows with values, no track); Rating bands has no Show track. The API frame gives the _Bar segment default as Colour 6; the component’s default is 1 — 6 is the instance pre-placed in the Extra segments slot. 100% stacked rows are drawn with plain segments rather than _Bar, so Show extra segments doesn’t reach them. Rating bands has no legend of its own, so the layouts here add one in the card. The Color Annotation’s Rating bands reference shows Aime at 4.1; the component says 4.7. The “Don’t squeeze long names under columns” example in Figma uses short month labels, and the “same axis” Don’t draws the rating line at the top of the plot; here they show long names and a flattened line so the problem is visible. The right axis has 6 ticks (5 → 0), the left 5. Show legend, Show grid, Show axis titles and Right axis are wired on Column, Column + line and Stacked with Stacks = 3, but not on the Stacked variants with Stacks = 2, 4 or 5 (those only respond to Show line); this page treats them as available on every Type, as the component description and API frame intend.
