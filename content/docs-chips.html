Chips, Tags & Legends

Stable Last updated Oct 2026

Small coloured labels that sit next to data. Chips label a value or category, Tags show a key → value pair, and Legends name a chart series. Use a Sementic preset whenever one exists for your data; otherwise configure a Standard one.

Guidelines Specifications Code (not in Storybook yet) Accessibility (coming soon)

At a glance

Five related components share one shape: a small rounded container with an optional leading icon, a label and an optional trailing icon. Pick the most specific one first — if a Sementic version exists for your data, use it; otherwise use the Standard one.

Three components, three jobs: chips describe, tags filter, legends explain a chart.

Chip

Labels a value or category — “100 gms”, “Cat: Snacks”.

Tag

Shows a key → value pair — a filter, rule or mapping.

Legend

Names a chart series, in the series colour.

Which one do I use?

Answer top to bottom and stop at the first “yes”.

#QuestionUse
1Is it a chart legend for a known metric (Top Selling, Grammage, Consumption / Offtake / KW share)?Sementic-legend
2Is it any other chart legend?Standard-legend
3Is it a value of a known data type (Grammage, Offtake %, Category, ASIN, MRP, SP, GMV, NSR, Top Selling)?Sementic-chip
4Does it show a key and a value together (filter, rule, mapping)?Standard-tag
5Anything else (category, status, label)?Standard-chip
6Can the user click it to select or filter?Not here — use Selection chips (Checkbox-chip / Radio-chip).

Common layouts

Chips sit next to data to label it. Tags show applied conditions. Legends sit above or beside charts. All of them are read-only labels.

Do’s and don’ts

Choosing the component

Do

100 gmsin (X)

Use the Sementic chip when one exists for your data. The same data looks the same on every screen.

Don’t

100 gmsin (X)

Don’t rebuild a data-type chip from a Standard chip in another colour. “100 gms” in green here and orange elsewhere breaks recognition.

Do

SnacksBeverages

Use chips and tags as labels; use Selection chips for things people pick. Read-only chips have no hover, selected or focus states.

Don’t

AllSelected?Other

Don’t use Standard-chip as a clickable filter. It looks static and gives no feedback when clicked.

Colour meaning

Do

In stockOut of stock

Pick colour for meaning: Red negative, Green positive, Yellow warning, Sec. Text neutral. People read colour before text.

Don’t

SnacksBeverages

Don’t use Red or Green for neutral categories. A red “Snacks” chip reads as an error.

Do

Personal carePersonal care

Keep one colour per meaning across a screen, so colour becomes a reliable cue.

Don’t

TagTagTagTagTag

Don’t give every chip a different colour “to look lively”. A rainbow of chips is noise.

Tags & legends

Do

BrandDettol

Tags are key → value, both short (“Brand → Dettol”). It reads like a rule or filter.

Don’t

StatusActive

Don’t use a tag where a single chip is enough. “Status → Active” is just an “Active” chip.

Do

Match the legend to the series colour and order of the chart, so people map legend → line instantly.

Don’t

This weekLast week

Don’t use legend colours that differ from the chart. Nobody can tell which line is which.

Writing content

  • Chip labels — 1–3 words or a formatted value: “Top 10”, “100 gms”, “12.4%”.
  • Sementic values — keep the preset’s format: “200 ml”, “12.4%”, “Cat: Snacks”.
  • Tags — key → value, both short: “Brand → Dettol”, “City → Mumbai”.
  • Legends — the metric or series name, exactly as the chart’s tooltip calls it.
  • Long labels — truncate with an ellipsis and show the full text in a tooltip; never wrap.

Behavior & accessibility

TopicWhat to do
WidthHugs content, up to a max-width. Truncate long labels with an ellipsis + tooltip; never wrap.
InteractiveChips have no hover, selected or focus states. For selectable filters use Selection chips (Checkbox-chip / Radio-chip).
Removable tagsSwap the suffix to × when the tag is an applied filter; the × is a button with an accessible name (“Remove Brand: Dettol”).

Adding one to a screen

Sementic-chip

  1. Insert and pick the Use case. Assets → “Sementic-chip”. Set Use case to your data type — colour and icon are set for you.
  2. Type the value. Double-click the text and enter the real value in the preset format (“200 ml”, “12.4%”, “Cat: Snacks”).
  3. Adjust emphasis or surface. De-emphasized = Yes for secondary chips in dense tables; Dark Mode = Yes on dark surfaces.

Standard-chip

  1. Insert and type the label. Assets → “Standard-chip”. Change the Label property.
  2. Choose colour by meaning. Red negative · Green positive · Yellow warning · Sec. Text neutral · Disabled unavailable · accents for categories.
  3. Pick type, size and shape. Filled (default) or Outlined. Tiny / Small in tables, Medium in cards, Large rarely. Is Rounded for pills; Icon Only for compact (+ tooltip).
  4. Set the icons. Swap “Prefix” to an icon that explains the value. Suffix Icon for Info or close.

Tag or legend

  1. Tag: key → value. Assets → “Standard-tag”. Edit the key and the value; pick colour and size like a chip. Swap Suffix to close if it can be removed.
  2. Legend: match the chart. Known metric → Sementic-legend (pick Use case); otherwise Standard-legend with Color = the series colour.

Before you hand off

  • Sementic component used wherever the data type has one.
  • Colours mean something and are consistent on the screen.
  • One size and shape per group; Small / Tiny in tables.
  • Labels are short; values formatted like the preset.
  • No default “Car” icon left on unrelated chips.
  • Legend colours match the chart series.
  • No Status-deprecated chips used.
  • Nothing clickable built from Standard-chip (use Selection chips).
