Slider

Lets users pick one value (Single) or a min–max range (Range) by dragging a handle along a rail. Use it when an approximate value on a known scale is good enough and seeing the position helps — price, discount, thresholds.

At a glance

Use a slider when an approximate value on a known scale is good enough and seeing the position helps — price, discount, thresholds. Type picks one handle or two, State covers Default, Hover, Active and Disabled, and the position is set in steps of 10. Drag the handle below, or focus it and use the arrow keys.

Use it for

Approximate values on a short, known scale: a price band, a discount, an alert threshold.

Pick the type

Single for one value; Range for a min–max filter (two handles that can’t cross).

Label it

The component has no label. Always place a label and the current value next to it; use an input for exact numbers.

How it’s built

One component, Slider, with 2 Types × 4 States — 8 variants. The position lives in a private nested Track: select it inside the Slider to set Value (Single) or Start / End (Range). No gap: the filled part sits on a continuous rail and the handle sits on top.

① Rail

Full-width 4px bar, radius 8 — Accent/Steel Blue/100. Stretches with the slider.

② Filled part

Primary/400, laid over the rail with no gap: from the start to the handle (Single) or between the two handles (Range).

③ Handle

18 × 12 pill, radius 8, Primary/600 with a 1px White border. Fixed size at any width.

④ Tooltip

Tooltip/Standard-hover-tooltip, 6px above the handle. Shows the value while dragging; filled in automatically.

⑤ _Slider track/Single

Private. Holds the handle position: Value 0–100 in steps of 10 (11 variants) and Show tooltip.

⑥ _Slider track/Range

Private. Start / End in steps of 10 with End above Start (55 variants), Show start tooltip and Show end tooltip.

Anatomy

A continuous rail with a filled part laid over it and a handle on top — no gaps. Single has one handle (value); Range has two (start and end). While dragging, the system Tooltip shows the value above the handle.

The handle position comes from the nested Track: Value for Single, Start and End for Range — 0 to 100 in steps of 10, End above Start. The handle is centred on its value, so at 0 and 100 it overhangs the ends of the rail by half its width.

How to add one in Figma

Step-by-step for designers.

Add a slider

  1. Insert and pick Type
    Assets → “Slider”. Single for one value, Range for min–max.
  2. Set the position
    Select the nested Track: Value (Single) or Start / End (Range), steps of 10.
  3. Stretch to the width
    Set width (Fill container or fixed ≥ 200). The handle stays 18 × 12; positions stay proportional.
  4. Show states in your flow
    Hover / Active (tooltip) for interaction specs; Disabled when it can’t be changed. Leave 34px above for the tooltip.

Before you hand off

  • Right type: Single for one value, Range for min–max.
  • Label and current value shown next to the slider.
  • Width ≥ 200px; 34px free above for the tooltip.
  • Position set with Value / Start / End (steps of 10).
  • Disabled used only with a reason shown.
  • Exact numbers → input field instead (or alongside).
