Slider

Lets users pick one value (Single) or a min–max range (Range) by dragging a handle along a rail. Use it when an approximate value on a known scale is good enough and seeing the position helps — price, discount, thresholds.

API and behavior

Designers: insert Slider, pick Type and State, set Value (Single) or Start / End (Range) from the nested Track, and stretch it to the width you need. Developers: <Slider type="single|range" value={40} | value={[20,60]} min={0} max={100} step={10} disabled onChange showTooltip="drag" />.

<Slider
  type="single"            // single | range
  value={40}               // range: value={[20, 60]}
  min={0}
  max={100}
  step={10}
  disabled={false}         // State = Disabled — keep the value visible
  onChange={setValue}      // apply on release (or debounce)
  showTooltip="drag"       // tooltip shows the value while dragging
  aria-label="Discount"    // the component has no label
/>

Source

Values come from the Slider — Documentation frames on the “Slider 🆕” page of the Cube Core Figma file (Anatomy, Property, Color Annotation, Dimensions, API, Usage Guidelines, How to use), the live Slider component set (Type × State), its “In context” frames, and the private _Slider track/Single and _Slider track/Range sets.

Where Figma disagrees with itself or leaves gaps: the How to use frame says “Add a slider in 5 steps” but shows four. The Dimensions frame fixes the height at 12, but the “In context” instances are stretched to 60 tall (the 12px track stays centred). The usage examples reserve 40px above the slider for the tooltip; the Dimensions frame says 34. The API frame gives Range as “End > Start” (and the Range track has no equal Start / End variant) while the behaviour rules say “Start ≤ End”; the live demos here keep at least one step between the handles. The anatomy describes the handle as Primary/600 — that is Default only; Hover and Active use Primary/700. The anatomy is drawn at 4× in Figma and at 3× here. The Figma keyboard rules list only ← / → and Home / End; the demos also accept ↑ / ↓.
