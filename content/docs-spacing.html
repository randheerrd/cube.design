Spacing

Stable Last updated Sep 2026

A single 21-step scale, 0–72, used for every padding, margin and gap in the product — the token name is always the pixel value. The Specifications tab lists every step.

Introduction

Every margin, padding and gap in Cube comes from one 21-step scale. Unlike Heading or Body in Typography, spacing has no named variants — the token name is the pixel value, so SPACING[16] is always 16px, whichever of the three properties it's set on.

Scale

21 steps — denser at the small end, opening up above 20px. The Specifications tab lists every one; here's which range to reach for:

TokenValueTypical usage
00pxNo spacing.
1-21–2pxHairline gaps.
44pxTight spacing — icon gaps, inline elements.
88pxCompact spacing — form fields, list items.
12-1612–16pxStandard spacing — card padding, section gaps.
20-2420–24pxComfortable spacing — panel padding.
32-4832–48pxGenerous spacing — page sections.
64-7264–72pxLarge spacing — page-level separation.

Applying spacing

The token replaces the raw value on whichever CSS property is doing the work — a margin between two stacked blocks, a padding around a card's content, or a gap on the flex/grid container arranging a row of children:

import { SPACING } from './atoms/spacing';

// Padding — a card's own inner edge
padding: SPACING[16]     // 16px

// Gap — space between children of a flex/grid container
gap: SPACING[24]         // 24px

// Margin — space between two stacked, unrelated blocks
marginTop: SPACING[32]   // 32px

Prefer a container's gap over margin on individual children when the children are a row or a list — one token then controls every space between them, and adding or removing an item never leaves a stray margin behind.

Designing with space

  • Relationships — close elements read as related. SPACING[4]–[8] between an icon and its label says "one control", the same gap a Button uses.
  • Hierarchy — more space around something raises its weight. A card's own content stays tight ([12]–[16]); the gap between cards opens up ([16]–[24]); whole page sections step up again to [64]/[72].
  • White space — even dense surfaces (a comparison table, a metric grid) keep a minimum SPACING[8] between values, or adjacent numbers start to run together.

FAQ

Can I use a value outside the scale?

No — a value between two steps usually means the layout needs a second look, not a new token.

Does spacing shrink for a dense table or a smaller screen?

The scale doesn't change; a dense or narrow layout just reaches for a smaller existing step (4–8 instead of 12–16). There's no separate compact or mobile scale.

How does this relate to the layout grid?

Grid columns and gutters are a separate foundation. This scale is for space inside and between components, not the column structure a page is laid out on.
