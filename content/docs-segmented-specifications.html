Segmented Control

New Last updated Oct 2026

A row of connected options where exactly one is active — used to switch views, periods or modes instantly. A Segmented-control (the track) holds 2–8 Segmented-elements (the options). Three types: Primary (solid, high emphasis), Secondary (tinted, low emphasis) and Accent (colour-coded).

Guidelines Specifications Code (opens Storybook in a new tab) Accessibility (coming soon)

Source

Taken from the Segmented Control documentation in the Copy-of-GC-Design Figma file and the Selection/Segmented-control library. Notes:

  • Secondary corners vary. The track note says “padding 2, radius 8” for every type, but the Secondary track has no padding and a 6px radius (8 at Large). Secondary segments mix 6 and 8 within one control. These pages use one radius per size (6 Small / Medium, 8 Large) for track and segments.
  • Hover and focus aren’t in the component. Hover here uses Secondary-text/50 (#f5f5f8, from the Chips docs) as Figma recommends; the focus ring is a code-side addition.
  • Accent colour names. “Teal” is bound to Accent/Light Blue/600 (#0084d1), and “Bronze Green” to Accent/Bronze/600 (#009689), which looks teal.
  • Accent fill radius. The nested Accent-background keeps a 6px radius inside pill segments and only looks right because it’s clipped. Code should give it the segment’s radius.
  • Accent shape. The Type caption says Accent is “Rounded only”, but the element mocks show Accent with 6px corners, and the element set still has non-rounded Accent variants.
  • Defaults disagree. The track defaults to Size = Medium; every segment element defaults to Size = Small.
  • Tab limits. Docs say 2–8 segments, but only Fit + Is Rounded = No variants go up to 8; Fill variants stop at 4 and rounded ones at 3.
  • Count chip and Pro tag change colour with selection; no Figma caption says so. Large labels use 0 letter-spacing (0.1px elsewhere).
  • The Pro gem, cube, chart and table icons on these pages are redrawn equivalents of the Figma icon assets.
  • In code the control maps to Storybook’s Navigation/Segmented.
