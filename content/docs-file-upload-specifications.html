File upload

New Last updated Nov 2026

A drop zone where users drag a file or click to browse to import data (inventory, sales, keywords, guardrails, assortment). It shows upload progress and a list of files, each with a status: ready, uploading, uploaded or failed. The Specifications tab lists every value.

API and behavior

Designers: place Upload, edit Title / Helper, turn on Progressbar while uploading and Slot2 to show the file list, then set each File upload item’s State. Developers: one files array drives the list — each file carries its own status, progress and message.

<FileUpload
  accept=".csv,.xlsx"
  maxSize="50MB"
  multiple
  title="Upload sales"
  helper=".CSV, .XLSX, .XLS · max 50 MB"
  files={[
    // status: "ready" | "uploading" | "done" | "error"
    {
      name: "final_template_210336.CSV",
      status: "uploading",
      progress: 91,               // drives the bar and the Count
      message: "Upload pending",  // the status line; on "error", the reason
    },
  ]}
  onAdd={addFiles}
  onRemove={removeFile}      // cancels the upload while it’s running
/>

Source

Values come from the File upload — Documentation frames on the File upload page of the Cube Core Figma file (Anatomy, Property, Color Annotation, Dimensions, API, Usage Guidelines, How to use) and the live Upload, _Progressbar and File upload item components in File upload · components (use these).

Where Figma disagrees with itself or leaves gaps: the colour table lists a grey CheckCircle for Neutral, but the Neutral item has no status icon — this page follows the component. The progress fill uses text/text-brand (#034ced), a text token; Figma flags it should be a fill token (Primary/600, #025be5) — the component value is shown. In Figma the fill is always 66px short of the end whatever the Count says; here the fill matches the %. Figma flags its own names for change: “Pprgress bar” (typo, single value, to be removed), “Slot2” (to become “Show file list”) and Size Default / medium / Variant3 (to become Small / Medium / Large); Title, Helper, File name and Status text are text layers, not properties. The upload-icon, remove-button, Count and FileText colours aren’t in the colour table; they’re read from the components. Upload has no template-link option yet, so the template-link pattern adds an Action-Button · Naked next to the drop zone. The Assortment and Offtake layouts are drawn from the product screenshots on the Figma page; the Offtake history adds a Status column built from the File upload item error style.
