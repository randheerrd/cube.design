Side Nav

The left panel people use to move around the product: a workspace switcher, the top-level pages, a platform filter, expandable module groups and a footer, in Light and Dark mode. The Specifications tab lists every value.

At a glance

The side navigation is the left panel people use to move around the product. From top to bottom: a workspace switcher, the top-level pages, a platform filter (QComm / EComm and platform logos), expandable module groups with up to three levels, and a footer. It comes in Light and Dark mode.

1 · You are here

Exactly one row is Selected — the current page. Its group is expanded, nothing else.

2 · Open only what’s needed

Expand only the module that holds the current page. Keep the others collapsed.

3 · Show the context

A platform is always selected in the grid — it changes the data on every module page.

How to set it up in Figma

  1. Insert the navbar
    Open Assets (⌥2), search “Navbar-V3”, drag it into your frame and place it at X 0, Y 0. Never detach it — every change below is made inside the instance.
  2. Pick the mode
    Select the navbar and set Mode to Light or Dark to match the product theme. The header, items and footer switch together.
  3. Set the workspace
    Double-click into the nav header and edit the workspace name; swap the logo if needed. Turn Arrows off if the user has only one workspace.
  4. Mark the current page
    Select the nav item of the page you are designing and set Interactive State to Selected. Every other item stays Default.
  5. Open the right module
    If the page lives inside a module, set that module group to Expanded = Yes, then set the sub-page to Selected. Keep the parent Default and leave other modules collapsed.
  6. Choose the platform
    Pick QComm or EComm, then set the active platform to Selected. Use Grid size “> 3x3” when there are more than about five platforms.
  7. Show locked and new features
    Pages the user can’t access: Locked, keep Hover Tooltip on and write the reason in your annotations. Recently launched pages: New feature = Yes (one or two at most).
  8. Fit it to the screen
    Stretch the navbar to the full frame height — the middle list scrolls, the header and footer stay pinned. Start the page content at X 256.

Before you hand off

  • The navbar is an instance of Navbar-V3, not detached.
  • The mode matches the screen theme.
  • Exactly one row is Selected — the current page.
  • Only the module that contains the current page is expanded.
  • A platform is selected in the platform grid.
  • Locked items have a tooltip reason in the annotations.
  • At most one or two NEW tags.
  • The navbar is full height and content starts at X 256.

Common questions

QuestionAnswer
How do I change an item’s icon?Select the icon layer inside the item and swap its Icon property. Keep the same icon set.
How do I rename a page?Double-click the label inside the instance and type. Keep it to one to three words.
I need a page that isn’t in the navbar.Don’t detach. Ask the design-system team to add it to Navbar-V3 so every screen stays in sync. For a quick exploration, duplicate the screen and mark it “Exploration”.
How do I show the navbar collapsed or on mobile?There is no collapsed or mobile variant yet. Flag it to the design-system team rather than building your own.
Can I hide an item the user can’t access?Prefer Locked with a tooltip so the feature stays discoverable. Hide it only if product explicitly asks.

Writing content

  • Page labels — one to three words in Title Case: “Geo Intelligence”, “Report Download”. Never wrap to two lines.
  • Icons — every top-level item has one, from the Nav icons set.
  • Module names — the product area: Digital Shelf, Performance Marketing, Setup & Integrations.
  • Locked tooltips — say why and how to get access: “Upgrade to access Geo Intelligence”.
  • NEW tags — one or two at a time, removed after a few weeks.

LockedNot navigable. Show a tooltip with the reason or the upgrade path.
