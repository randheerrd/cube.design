Dashboard widget

The card that holds each block of a dashboard: a Widget-header with the name, context and tools, and a slot for one content block. The Specifications tab lists every value.

API and behavior

Designers place Dashboard-widget, configure the nested Widget-header and insert one content block into the slot. In code the header is configured by props and the content is passed as children.

<Widget
  header={{
    icon: ChartLine,
    title: "Revenue trend",
    at: "MRP",
    for: "All Cat.",
    watermark: false,
    tools: ["legend", "iconButton"],
    collapsible: true,
  }}
>
  <TrendsComposition … />
</Widget>

Source

Values come from the Dashboard widget — Documentation frames in the Cube Core Figma file (Anatomy, Property, Color Annotation, Dimensions, API, Usage Guidelines, How to use) and the live Dashboard-widget and Widget-header components.

Where Figma disagrees with itself: the Color doc gives the widget background as a raw #EFF2F6 that “should be a token”; in the component a white layer sits on top, so the card shows white — this site uses white. The Dimensions doc gives a fixed 110 gap between title and tools and says it should be “space between”; this site uses space between so the header never overflows. The Color doc lists the “at” / “for” labels as Medium 12; the component uses Medium 14. Legend, Drop-down, Search, Icon Button and Collapsible default to on, although the guidance is to keep four tools at most. Metric-card-widget-deprecated is deprecated — don’t use it.
