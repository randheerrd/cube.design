Icons

Cube uses Phosphor Icons in three weights, through one Icon component that takes its size, weight and colour from tokens. The library lists every icon.

Cube Core

Figma
Guidelines Specifications Code (not in Storybook yet) Accessibility (coming soon)

At a glance

Cube uses Phosphor Icons — about 1,500 icons on one 256 × 256 grid, MIT-licensed, the same set as the Icons library in Figma. Product code never imports Phosphor directly: every icon goes through Cube’s Icon wrapper, so size, weight, colour and accessibility come from tokens.

One library

Phosphor in Figma and code, with the same names. Need an icon? Search the library below.

Three weights

Regular by default, Bold for emphasis, Fill for active and selected states.

Colour follows text

Icons use currentColor, so they take the colour of the text or button they sit in.

SearchFiltersExport

Regular icons beside labels; Fill marks the active item (the filled house and bell are the “current” states).

Icon library

Every Phosphor icon, searchable by name, tag or category. Pick a weight, then click an icon to copy its React import or HTML.

Weights

Phosphor ships six weights. Cube uses three; Thin, Light and Duotone are left out unless design asks for them.

Regular Default

The default for every icon in the product: navigation, buttons, fields, tables.

Bold

Emphasis at small sizes, or next to SemiBold and Bold text.

Fill

Active and selected states — the current nav item, a toggled favourite — and header icons in popups.

Sizes

Six sizes from the icon size token. Match the icon to the text beside it — 14 with 12px text, 16 with 14px text.

Offtake

xs · 12

Inside chips, badges and the 10/12 tooltip text.

Offtake

sm · 14

Medium components: 12px labels, Medium inputs, inline and chip controls.

Offtake

md · 16 Default

The default. Large components and 14px body text.

Offtake

lg · 20

Side nav, page headers, empty-state icons in cards.

Offtake

xl · 24

Section headers, large touch targets.

Offtake

2xl · 32

Feature and empty-state illustrations.

Cube’s components use 14 and 16 most, so the scale includes 14 — the Phosphor guide’s suggested scale (12 / 16 / 20 / 24 / 32, default 20) doesn’t.

Colour

Saved2 issuesDelete

Inherit the text colour

Leave colour as currentColor; set the colour on the text or button, and the icon follows.

Use text tokens

Primary-text/950 for strong, Secondary-text/700 for default, Disabled/400 when disabled.

Icons that carry meaning on their own need 3:1 contrast with their background (WCAG 1.4.11).

Do’s and don’ts

Four rules in two groups.

Weight and size

Do

HomeReportsSettings

Use Regular, and switch to Fill only for the active item.

Don’t

HomeReportsSettings

Don’t mix weights in one group. It looks like several states at once.

Do

Last 30 days

Match the icon to the text: 16 with 14px text.

Don’t

Last 30 days

Don’t make the icon much bigger than the label. It pulls the eye away from the words.

Meaning

Do

Delete

Give icon-only buttons a label and a tooltip.

Don’t

Don’t ship an icon-only button with no name. Screen readers announce nothing.

Do

Delete

Use the approved icon for the idea: Delete is trash everywhere.

Don’t

Delete

Don’t pick a different icon for the same action on another screen.

In Figma

  • Use the Icons library in the Cube Figma file; it is Phosphor, with weights as a variant (Weight=Regular).
  • Swap icons through the component’s icon property (for example Prefix Icon) rather than detaching.
  • Keep Figma component names the same as the semantic names in the registry, so design and code match.
  • The official Phosphor Figma plugin has every icon and weight if one is missing from the library.

Accessibility

CaseWhat to do
Icon next to visible textDecorative: aria-hidden="true", no label. This is the wrapper’s default.
Icon-only buttonPut aria-label on the button (or pass label to the icon) and add a tooltip.
FocusIcons are never focusable themselves; the button or link around them is.
Contrast3:1 against the background for icons that carry meaning.
Right-to-leftUse mirrored for direction icons: arrows and carets.

Tokens, the React wrapper and setup are on the Specifications tab.
