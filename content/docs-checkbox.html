Components

Checkbox

New Last updated Oct 2026

Lets people pick zero, one or many options from a set. The family has five components: the bare Check-box control (+ accent colours), Checkbox-inline (control + label, for lists) and Checkbox-chip (bordered chip, for filter bars) (+ accent colours).

Guidelines Specifications Code (opens Storybook in a new tab) Accessibility (coming soon)

At a glance

Try it: tick some categories — “All categories” turns into a dash (Intermediate) when only some are selected, and clicking it selects all. Then pick any platforms in the chip row. These are real checkboxes: Tab to one and press Space.

Category

Platforms

Checkbox-inline (Large) with a parent “select all”, and Checkbox-chip (Medium) with platform logos.

Checkbox-inline

Control + label — lists, dropdown menus, forms, settings.

Checkbox-chip

A bordered chip — filter bars and compact multi-select groups.

When to use

Use a checkbox when people can pick any number of options — including none — and each choice is independent. Pick the component by context first, then set State and Size.

You need to…UseWhy
Pick any number of options from a listCheckbox-inlineControl + label; scans well in lists, menus and forms.
Filter a view with a few options in a barCheckbox-chipCompact and clickable; the selected look is easy to spot.
Select rows in a tableCheck-box (bare)The row itself is the label; a header checkbox selects all.
Filter chart seriesCheckbox-chip-accentThe chip colour matches the series it shows or hides.
Pick exactly one optionRadio / Selection groupCheckboxes allow several; one-of-many needs a radio.
Turn a setting on or off instantlyToggleA toggle applies at once; a checkbox usually waits for Save / Apply.
Switch between viewsSegmented controlViews are mutually exclusive.

Need a titled group of checkboxes with consistent spacing? Use the Selection group (Multi select).

Anatomy

1 · Check-box control

Selection-control/Check-box — the bare control used inside every other checkbox component. Shown: State = Selected, Size = 16, at 8×.

#ElementFigmaNotes
1ContainerframeFixed 14 × 14 or 16 × 16 frame (Size property). Defines the hit area inside inline / chip components — never resize it manually.
2BoxframeRounded square inset 1px inside the container (12 or 14px). Unselected: 1px outline (Secondary-text/700). Selected / Intermediate: solid fill (Primary/600, or accent colour).
3Check / dash glyphvectorWhite check mark (Selected) or horizontal dash (Intermediate). Cut out of the same vector as the box — it is not a separate swappable icon.

2 · Checkbox-inline

Selection/Selection-inline/Checkbox-inline — control + label, used in lists, dropdowns and forms. Shown: Size = Large, State = Selected, with Prefix Icon, Info and Pro enabled, at 3×.

#ElementFigmaNotes
1ContainerframeHorizontal auto-layout, no fill, hugs content. Gap 4 (Medium) / 6 (Large). The whole row is the click target.
2Check-box controlinstanceNested Selection-control/Check-box — Size 14 for Medium, 16 for Large. Its State follows the parent State.
3Prefix icon / Platform logoinstanceOptional. “Show Prefix Icon” + “Prefix Icon” (instance swap, default Cube) or “Show Platform” (20px platform logo). Use one or the other, not both.
4LabeltextTEXT property “Label”. DM Sans Medium 12/16 (Medium) or 14/18 (Large); becomes SemiBold + Primary-text/950 when Selected.
5Info iconinstanceOptional “Show Info ℹ️” — sits right after the label; attach a tooltip explaining the option.
6Pro taginstanceOptional “Pro 💎” — marks options that need a paid plan. Pair with Locked 🔒 (disabled variants) when the user has no access.

3 · Checkbox-chip

Selection/Selection-chip/Checkbox-chip — bordered chip with a checkbox, used in filter bars and multi-select groups. Shown: Size = Large, State = Selected, with Prefix Icon, Info and Color Legend enabled, at 3×.

#ElementFigmaNotes
1ContainerframeAuto-layout chip: height 28 (Medium) / 32 (Large), padding 8 / 10, radius 6 / 8, 1px border. Fill and border change with State (see Color tokens).
2Check-box controlinstanceNested Check-box (14 / 16). Accent chips nest Check-box-accent in the matching colour.
3Prefix icon / Platform logoinstanceSame optional slots as Checkbox-inline (“Show Prefix Icon” / “Prefix Icon” / “Show Platform”).
4LabeltextTEXT property “Label”. Medium weight; SemiBold + Primary/700 (or accent 700) when Selected.
5Info iconinstanceOptional “Show Info ℹ️”.
6Color legendframeOptional “Show Color Legend” — 7px dot that ties the chip to a chart series. Use when the chip filters a chart.

4 · Disabled & Locked

Disabled = Yes greys out the control and label. Locked 🔒 (available on disabled inline / chip variants) explains why an option is unavailable. Shown: Checkbox-inline, Large, Disabled, Locked, at 3×.

#ElementFigmaNotes
1Disabled controlinstanceCheck-box with Disabled = Yes — Disabled/50 fill, Disabled/400 border (or Disabled/400 fill when selected).
2Disabled labeltextLabel switches to Disabled/400. Keep the label readable — don’t hide unavailable options, disable them.
3Pro taginstanceOptional — tells the user the option is locked behind a plan.
4Lock iconinstance“Locked 🔒” — shown after the label on disabled variants. Add a tooltip with the reason / upgrade path.

Component family

Five components. Pick by context first, then configure State / Size.

Check-box

Bare control. Tables (row select), custom layouts, inside other components.

Check-box-accent

Bare control in one of 8 accent colours — ties a selection to a chart series.

Checkbox-inline

Control + label. Lists, dropdown menus, forms, settings.

Checkbox-chip

Bordered chip. Filter bars and compact multi-select groups.

Checkbox-chip-accent

Chip in an accent colour — chart legends that double as filters.

Check-box

Selection-control/Check-box. Four states, each with a Disabled version, shown at 2×. Hovered + Disabled looks identical to Default + Disabled (no hover feedback).

DisabledDefaultHoveredSelectedIntermediate
No
Yes
  • Default — unchecked. 1px outline, Secondary-text/700.
  • Hovered — pointer over the control or its label. Darker outline + light fill.
  • Selected — checked. Primary/600 fill with white check.
  • Intermediate — indeterminate: a parent whose children are partly selected. Clicking selects all.
  • Disabled — unavailable. Selected · Disabled means checked but locked (e.g. a mandatory option).

Accent colours

Accent versions tie a selection to a chart series. Unselected accent controls and chips look exactly like the base ones — colour only appears when Selected.

Check-box-accent

Size 14 only, no Intermediate. Light Blue and Green use the /700 step for contrast; Yellow maps to Semantics/Warning.

Selected, at 2×.

Common layouts

Bare check-boxes for table rows, Checkbox-inline in menus and forms, chips in filter bars, and accent chips as chart legends that double as filters.

Do’s and don’ts

Do

Write labels as a clear statement that is true when checked.

Don’t

Don’t use negative labels — “checked” should never mean “no”.

Do

Use radios when only one option can be picked.

Don’t

Don’t use checkboxes for mutually exclusive options.

Do

Show Intermediate on a parent when only some children are selected.

Don’t

Don’t show the parent as fully checked when some children aren’t.

Do

Disable unavailable options, add Locked and a tooltip with the reason.

Don’t

Don’t hide options people can’t use — they won’t know they exist.

Do

Use accent chips only when each colour matches a chart series.

Don’t

Don’t use accent colours as decoration — use the base Checkbox-chip.

Writing content

  • Labels — short and positive, sentence case: “Include out-of-stock SKUs”, not “Don’t exclude…”.
  • Parallel — options in one list are the same kind of thing (all categories, all platforms).
  • Order — most-used first, or a natural order (alphabetical for long lists).
  • One line — labels truncate with an ellipsis; put extra detail in the Info tooltip, not the label.
  • Locked — the tooltip says why and how to get access: “Available on the Pro plan”.

Behavior & accessibility

TopicWhat to do
Click targetThe whole row (inline) or chip is clickable, not just the 14 / 16px box.
IndependentEach checkbox toggles on its own. Zero, one or many can be selected.
IntermediateOnly on a parent. Click → selects all children; click again → clears them. It is set from code (input.indeterminate), never by the user directly.
ApplyIn forms, values save with the form’s button. In filter bars, apply on change (or with an Apply button for slow queries).
SemanticsA native <input type="checkbox"> inside its <label>. Bare check-boxes need an aria-label (e.g. “Select row: Amul Taaza 1L”). Group related ones in a fieldset + legend.
KeyboardTab moves between checkboxes; Space toggles. Disabled checkboxes are skipped.
FocusShow a visible 2px Primary/600 focus ring around the box (inline) or the chip.
