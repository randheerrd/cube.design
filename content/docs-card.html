Components

Card

A bordered container for one item — a product, a group, an action, a KPI, a cause of loss or an account. Every card has a header, a main value, optional supporting metrics and an optional footer action; nine types reuse the same building blocks, and one card per row is Selected.

At a glance

Use cards to show one item per card in a row users scan and pick from. Type picks the layout, State picks Default or Selected, and toggles show or hide parts — toggles only appear on the types that have that part.

How it’s built

One component, Card, with 9 Types × 2 States (Account has Default only) — 17 variants. Every card is a bordered container (radius 6–8, padding 10–12); the types reuse the same building blocks.

① Delta

Triangle + % change. Medium on value rows, with the absolute change in brackets (“▲ 52.3% (₹52 L)”); Small in metric rows.

② Standard-chip

Orange Small pack chip (“12 pcs”) on Product compare; a category and a pack chip on Product list item.

③ Divider

Subtle (Secondary-text/100) line above supporting metrics and footers.

④ Buttons

Accent Outlined 24px platform button (chart icon); Outlined Small “Compare SKUs ›” or Naked “View ASINs ›” in the footer.

⑤ Avatar / SKU image

SKU thumbnail 40 × 40, radius 6 (Product compare); 36px Avatar (Product list item).

⑥ Icon / Status

Success · Warning · Error · Info status icon for the Account card.

Anatomy

Top to bottom: header (image or icon, title, platform button) → chips → main value + delta → highlight row → supporting metrics → footer action. Four types shown; the others use the same parts.

Common layouts

Use cards to show one item per card in a row users scan and pick from. Pick the type by what the card represents: Product compare / Group compare for side-by-side comparison, Category summary as the “selected” anchor at the start of a row, Action for recommended actions, KPI for a single number, Loss driver for each cause of a loss, Account for connected accounts. One card per row is Selected; the rest are Default. Click a card below to select it.

Writing content

  • Title — the real name of the item: a product (“Nivia Stormwhite Rubber Football”), a group (“Antipigment”), or an action (“Prioritize PO”). Max 2 lines on Product compare; longer names end in an ellipsis with a tooltip. Never ship “sample@email.com”.
  • Label — what the selection is: “Selected group SPGR” on a Category summary. Never ship “Metric label”.
  • Value — the main number with its currency and unit: “₹1,502”, “₹1.9 lac”.
  • Delta — the % change; on value rows add the absolute change in brackets: “▲ 52.3% (₹52 L)”.
  • Supporting metrics — short names, the same ones in the same order on every card in a row: “Wt. OSA %” · “Wt. Discount %” · “ASP” for products, “ASP” · “CVR” · “GVs” for groups.
  • Share — on Loss driver, the loss as a share of offtake: “0.1% of Offtake”. Keep “of Offtake” on every card in the row.
  • Secondary metric — on Loss driver, the driver’s own KPI: “Overall Fill Rate%” on Fill Rate, “Avg. Delivery Time” on Delivery Time.
  • Footer action — the same label across the row: “Compare SKUs” on products, “View ASINs” on groups.
  • Chips — small facts about the item: pack size (“12 pcs”), category (“Cat: Matchbox”).

Build a row of cards in 5 steps

  1. Insert and pick the Type
    Assets → “Card”. Set Type (see Step 0).
  2. Fill the text
    Title, Label, Value. Edit metric names / values and the delta in the layers.
  3. Toggle the parts
    Same toggles on every card in the row: image, chips, highlight, metrics, metric deltas, footer.
  4. Lay out the row
    Horizontal auto-layout, gap 12, cards 260 wide. Optional Category summary as the first card.
  5. Mark the selected card
    State = Selected on exactly one card; the rest stay Default.

Before you hand off

  • Right Type for what the card represents.
  • Same type and toggles across the row.
  • Exactly one Selected card per row.
  • Real titles (no “sample@email.com” / “Metric label”), max 2 lines.
  • Footer action consistent across the row.
  • Loading state designed (Skeleton / Card pattern).

HoverRaise the shadow and show a pointer cursor — only on selectable cards.
Footer actionOpens the detail (“Compare SKUs”, “View ASINs”). Does not change the selection.
Platform buttonOpens the platform breakdown.
Long title2 lines, then an ellipsis. A tooltip shows the full name.
LoadingSkeleton — Card or Plan card pattern, the same size as the card.
Clickable cardrole="radio" / aria-pressed with keyboard focus. Enter / Space selects.
