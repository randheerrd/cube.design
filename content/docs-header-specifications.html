Components

Header

The bar at the top of every product page, right of the navbar. Three stacked rows — what page and which period, sub-view tabs and page actions, and filters — switched on per page. The Specifications tab lists every value.

In the Figma file’s code export, the download and Outlined buttons are bound to button2 and the Filled button to button1 — the opposite of the docs, which say Button 1 is Outlined and Button 2 is Filled. Check with the design team before relying on the property names.

API and behavior

Designers: place Page header v2, set Module Name and platform, then toggle rows and info pieces per page. Developers: one header shell with three rows; time period, compare-with and filters are global page state (URL parameters) shared by every widget on the page.

TopicRuleNotes
StickyRow ① stays at the topRows ② and ③ scroll with the page.
Global statePeriod, compare and filtersChanging them refreshes every widget; keep them in the URL.
Compare withHidden on real-time pagesFor example Supply Chain Action.
NavigationSegmented tabs or Primary tabsNever radios.
Darkstore stripClickableThe arrow opens the store list.
