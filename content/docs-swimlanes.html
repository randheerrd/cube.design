How swimlanes are built

Build from the outside in: place ① Swimlanes-composition, fill its Columns slot with ② Swimlane-Columns, and fill each column’s Metric cards slot with ④ Swim Lane Cards — one per row in ③ Swimlane-labels.

① Composition

The whole block on the page. Contains the label column and the Columns slot.

② Columns

One per brand, category or item. A header, the metric cards and the actions.

③ Labels

Row names, on the left. One Metric-label-card per row, the same height as the cards beside it.

④ Cards

One per row in each column: Amount, % or Locked.

Swimlanes or another view?

Use swimlanes when users need to compare 3–8 items (brands, categories, platforms) across the same 3–8 metrics and then drill into one. For one item over time use a trend chart; for many items (10+) or many columns of numbers, use a table.

NeedUse
Compare 3–8 items across the same metrics, then drill into oneSwimlanes
See how one or a few metrics change over timeTrends-composition
Scan / sort many items (10+) or many numeric columnsTable-template
A few headline numbersMetric-trends-group

Writing content

  • Column headers — the item’s name only: a brand, category or platform (“Whole Wheat Atta”). Rename every header; never ship “Header”.
  • Row labels — the metric’s short name (“Sales”, “Est. Cat. Share”). Use the ⓘ icon for the definition rather than a longer label.
  • Values — Amount cards carry the unit (“₹69.6 Lacs”); % cards carry the percent sign (“62.8%”). One format per row.
  • Deltas — change vs. the previous period, with the absolute change in brackets: “▲ 14.5% (₹8.5 L)”. Sub-metric text and delta values aren’t properties — edit the layers.
  • Locked — name the metric: “Cat. share is locked”, then “Upgrade to Pro”.
  • Actions — 2–3 short verbs or destinations (“View Trends”, “Competition”, “Cross Platform”), the same in every column.

How to add one in Figma

Work from the outside in.

  1. Put it in a widget
    Add a Dashboard-widget and insert Swimlanes-composition into its content slot. Turn on Search in the widget header if users need to find items.
  2. Set the rows (labels)
    Fill Swimlane-labels with one Metric-label-card per metric (Sales, Est. Cat. Share…). Height “1 sub metric” for rows whose cards show sub-metrics.
  3. Add the columns
    In the Columns slot, add one Swimlane-Column per item (3–8). Rename each column header (brand / category name).
  4. Fill each column with cards
    In each column’s Metric cards slot, add one Swim Lane Card per row, in the same order as the labels. Type: Amount / % / Locked. Turn Sub-metric 1 / 2 on where needed.
  5. Select one column
    Set Selected = Yes on the focused column, and Selected = Yes on its cards.
  6. Set the actions
    Drilldown on for “see details”. Generic actions: keep 2–3 buttons (View Trends, Competition, Cross Platform), the same for every column.

Before you hand off

  • Swimlanes-composition is inside a Dashboard-widget.
  • Every column has the same rows in the same order as the labels.
  • Label heights match card heights.
  • Exactly one column is selected, and its cards are Selected too.
  • Card types match the data (Amount / % / Locked).
  • The same 2–3 actions in every column; Drilldown on.
  • Empty = Yes is designed for no results.
  • Horizontal scroll is noted when there are more columns than fit.

Behavior & accessibility

TopicWhat to do
Select columnClick the header or the column. The selected column highlights; Drilldown and the actions target it. One column at a time.
Row alignmentRender the label column and every column from the same rows array, so card heights per row are equal across columns and labels.
OverflowHorizontal scroll. The label column stays fixed (sticky) while the columns scroll.
LockedShow a Locked card, not an empty one. “Upgrade to Pro” goes to the plans page.
EmptyEmpty = Yes after a search or filter with no matches.
SortingOptional, by row: order the columns by the selected row’s metric.
KeyboardColumn headers are <button>s with aria-pressed; the columns area is focusable so arrow keys scroll it.
