Swimlanes

New Last updated Oct 2026

A side-by-side comparison view: each column is one item — a brand, category or platform — and each row is one metric. People scan across a row to compare, select a column to focus on it, and drill down from it. The Specifications tab lists every value.

Guidelines Specifications Code (not in Storybook yet) Accessibility (coming soon)

At a glance

Swimlanes put several items side by side. Each column is one item (a brand, category or platform); each row is one metric (Sales, Category share, Coverage…). It always sits inside a Dashboard widget.

Compare across a row

Every column has the same rows in the same order, so a value lines up with its neighbours.

Focus on one column

Select one column. Its cards and actions follow, and the drilldown targets it.

Built from four parts

Swimlanes-composition → Swimlane-labels + Swimlane-Columns → Swim Lane Cards.

Swimlanes or another view?

Use swimlanes when people compare a handful of items on the same metrics and then dig into one.

Writing content

  • Column headers — the item’s own name: “Whole Wheat Atta”, “Amul”, “Blinkit”. Keep it short; long names truncate with a tooltip.
  • Row labels — the metric name as it appears elsewhere in the product: “Sales”, “Est. Cat. Share”, “Wt. OSA %”. Use the info icon for the definition.
  • Values — Amount cards use ₹ with Lacs / Cr (“₹69.6 Lacs”); % cards use one decimal (“62.8%”).
  • Deltas — an arrow, the % change and the absolute change in brackets: “▲ 14.5% (₹8.5 L)”.
  • Locked — “<Metric> is locked” + “Upgrade to Pro”.
  • Actions — short destinations: “View Trends”, “Competition”, “Cross Platform”.

    Add a Dashboard-widget and insert Swimlanes-composition into its content slot. Turn on Show Search in the widget header if people need to find items.
  2. Set the rows (labels)
    Fill Swimlane-labels with one Metric-label-card per metric (Sales, Est. Cat. Share…). Set Height to “1 sub metric” for rows whose cards show sub-metrics.
  3. Add the columns
    In the Columns slot, add one Swimlane-Column per item (3–8). Rename each column header to the brand, category or platform.
  4. Fill each column with cards
    In each column’s Metric cards slot, add one Swim Lane Card per row, in the same order as the labels. Set Type (Amount / % / Locked) and turn Sub-metric 1 / 2 on where needed.
  5. Select one column
    Set Selected = Yes on the focused column, and on its cards.
  6. Set the actions
    Turn Drilldown on for “see details”. Keep two or three generic buttons (View Trends, Competition, Cross Platform), the same for every column: Button 1–3 on, Button 4–5 off.

Before you hand off

  • Swimlanes-composition is inside a Dashboard-widget.
  • Every column has the same rows in the same order as the labels.
  • Label heights match card heights.
  • Exactly one column is selected, and its cards are Selected too.
  • Card types match the data (Amount / % / Locked).
  • The same two or three actions in every column; Drilldown on.
  • Empty = Yes is designed for no results.
  • Horizontal scroll is noted when there are more columns than fit.

Behavior & accessibility

TopicWhat to do
Select a columnClick the header or the column. The selected column highlights and the drilldown and actions target it. The header is a <button> with aria-pressed.
Row alignmentRender every column and the labels from the same rows array, so card heights per row are equal across columns and labels.
OverflowColumns scroll sideways; the label column stays fixed (sticky). The scroll area is focusable (tabindex="0") and labelled, so keyboard users can scroll it.
LockedShow a Locked card, never an empty cell. “Upgrade to Pro” goes to the plans page.
EmptyEmpty = Yes after a search or filter with no matches. Keep the labels visible.
SortingOptional: order columns by the selected row’s metric.
DeltasDon’t rely on colour alone: keep the ▲ / ▼ arrow and the sign, and give screen readers “up 14.5%”.
SemanticsExpose it as a table: the row labels are row headers (th scope="row") and the column headers are column headers, so a screen reader can read “Sales, Whole Wheat Atta, ₹84.2 Lacs”.
