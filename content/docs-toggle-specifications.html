Toggle

Stable Last updated Oct 2026

A switch that turns a single setting on or off with immediate effect. One component (Toggle-switch) with three sizes, an on / off state, a disabled state and optional prefix / suffix labels.

Properties

Selected maps to the switch’s checked value, and the change applies immediately. In code use role="switch" with aria-checked, and connect the label so clicking it toggles the switch.

Source

Taken from the Toggle documentation in the Copy-of-GC-Design Figma file and the Toggle-Switch component. Differences from Figma:

  • The Large suffix label is 14 / 18 here (12 / 16 in Figma, flagged there as a mistake).
  • Some track paddings in Figma don’t add up (Medium off: 3 + 20 + 22 = 45 in a 42 track; Small on: 17 + 14 + 3 = 34 in a 32 track). Here the knob is positioned from the track padding and slides by the documented travel (18 / 16 / 12).
  • Hover and focus states are added in code; the component has neither.
  • The API frame is drafted at 50% opacity in Figma; its values match the component’s properties.

The code equivalent in Storybook is Controls / Toggle.
