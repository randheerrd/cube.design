Tables show many items with many attributes so people can scan, sort, compare and act on them. Use one when there are 10 or more items with several values each.

How a table is built

Build from the outside in. Five nested layers:

Table-template

Toolbar, a “Table columns” slot and the footer. Always start here.

Table-Column

One column. Pick its Type: Selection, Leading, Display, Display-divided or Action.

Header + Cell group

Each column is a Column header on top and a Cell group below.

Table cell

One row’s cell: State and Height.

Cell content

What the cell shows: SKU, %, Amount, Number, Platform, Chip…

Writing content

  • Header text — the metric’s short name in sentence case: “Offtake”, “Wt. OSA%”, “Est. Cat. Share”. Explain it with Show Info, not a longer title.
  • Units — in the value, not the header: “₹57.4 L”, “76.2%”.
  • Status text — one or two words: “Active”, “In Progress”, “Action Required”.
  • Row actions — a verb: “View”, “Edit”. Put the rest under More.
  • Real data — replace placeholder SKU names and numbers before hand-off.

How to build one in Figma

  1. Insert the template
    In Assets, use “Table-template”. Put it inside a Dashboard-widget slot (or a page) — it fills the width.
  2. Set the toolbar and footer
    Show supporting-elements: turn on only Search, Filter, Download or Column select as needed. Show Footer for paginated tables.
  3. Arrange the columns
    In the “Table columns” slot, order them Selection → Leading → Display… → Action. Add or remove Table-Column instances and pick each column’s Type.
  4. Set the headers
    Header text, Align (Right for numbers), Show Sort and Show Info. Use the same header Height across columns.
  5. Pick the content type
    On each column’s Cell-group set Cell Value (Amount, %, Number, Platform, String…). Leading: SKU for products.
  6. Set the row height and states
    One Size for all cells (52 for SKU rows, 48 or 36 for data). Own Brand for the user’s items, Selected for checked rows, Error/Breach for threshold breaches — across the whole row.
  7. Fill in real values
    Replace placeholder SKU names and numbers with realistic data — long names, big and small numbers — to test truncation and alignment.

Before you hand off

  • Built from Table-template (not the old “Table”, and not hand-drawn).
  • Column order: Selection → Leading → Display → Action.
  • Numbers right-aligned; headers named; sort and info where useful.
  • The right content type in each column (Amount, %, Platform…).
  • One row height; row states applied to whole rows.
  • The toolbar shows only the tools you need; a footer for paginated data.
  • Empty and loading states designed.
  • Sticky header and leading column noted for developers.

TopicWhat to do
SemanticsA real <table> with <th scope="col"> headers (scope="colgroup" for Display-divided). Give it a caption or aria-label.
SortingClick a sortable header; one column at a time. Make the header a <button> and set aria-sort on the th.
SelectionThe header checkbox selects none, all or some (Intermediate). Show the count in the toolbar and footer. Label each row checkbox with the row’s name.
HoverThe whole row highlights: every cell uses State = Hovered.
StickyKeep the header and the leading column visible while scrolling.
PaginationRows per page plus page buttons. Reset to page 1 when filters change.
