Accordion

New Last updated Nov 2026

A header that expands to reveal more content and collapses to save space. Use it for FAQs, optional detail and long pages split into sections people open one by one (Recommended Add-Ons, Plans & pricing, Competitor brands). Three styles for three weights of content. The Specifications tab lists every value.

Guidelines Specifications Code (not in Storybook yet) Accessibility (coming soon)

At a glance

A header that expands to reveal more content and collapses to save space. The whole header row is the toggle; the expanded state adds a short description and, with Show Slot on, any content you insert — a list, a table, cards.

Use it for

Content that is optional or long and users only need some of: FAQs, help text, secondary sections of a page.

Three styles

Underline (compact) < Bordered < Prominent (sections). Match the style to the weight of the content.

Not an accordion

Information users need for their main task. Don’t hide it — show it directly instead.

Anatomy

A clickable header that shows or hides the content below it. Header = title + toggle icon. Expanded adds a description and an optional content slot.

Common layouts

Use an accordion when content is optional or long and users only need some of it: FAQs, help text, secondary sections of a page. Don’t hide information users need for their main task — show it directly instead.

Writing content

  • Title — a clear question (“How is ROAS calculated?”) or a section name (“Recommended Add-Ons”). Never a vague label like “More info”: users scan titles to find what they need.
  • Description — the short answer or summary, shown when expanded. On Prominent, an optional one-line intro.
  • Slot — anything richer than a sentence: lists, tables, cards, pricing plans. Build it from system components.
  • What goes inside — only optional or secondary content. If users need it for their main task, show it directly instead.

How to add one in Figma

Step-by-step for designers: building an accordion list or section.

  1. Pick the style
    Underline: compact lists inside cards / panels. Bordered: FAQ and settings lists. Prominent: big page sections with rich content.
  2. Write the title
    A question (“How is ROAS calculated?”) or a section name (“Recommended Add-Ons”).
  3. Add the content
    Set State = Expanded to design the open state. Use Description for a short answer; turn Show Slot on for anything richer (lists, tables, cards).
  4. Stack and decide defaults
    Stack items in an auto-layout (8px gap for Bordered, 0 for Underline), full width. Note which items start open and whether only one can be open at a time.

Before you hand off

  • Content is optional / secondary (not core info).
  • Style matches the weight; one style per list.
  • Titles are clear questions or section names.
  • Expanded state designed; slot content uses system components.
  • Default open / one-at-a-time behaviour annotated.
  • No nested accordions.

Behavior & accessibility

TopicWhat to do
ToggleClick, Enter or Space on the header. The whole header row toggles, not just the icon.
AnimationHeight, 150–200ms ease.
Multiple openAllowed by default. Offer an optional “one at a time” mode for FAQs.
Default stateCollapsed for FAQs; the first section open for page sections.
PersistenceOn long pages, remember which sections each user opened.
HeaderA <button> with aria-expanded and aria-controls pointing at the content.
ContentA region labelled by the title.
FocusA visible focus ring on the header. There is no focus or hover variant in Figma yet.
BackgroundNone — the accordion inherits the surface it sits on, so there is no hover fill.
