Accordion

A header that expands to reveal more content and collapses to save space. Use it for FAQs, optional detail and long pages split into sections people open one by one (Recommended Add-Ons, Plans & pricing, Competitor brands). Three styles for three weights of content. The Specifications tab lists every value.

API and behavior

Designers: pick the Style by the weight of the content, set Title / Description, and turn on Show Slot to add content. Developers: <Accordion variant="bordered|underline|prominent" title description expanded onToggle>{children}</Accordion> — the header is a button with aria-expanded.

<Accordion
  variant="bordered"            // "bordered" | "underline" | "prominent"
  title="How is ROAS calculated ?"
  description="ROAS is attributed sales divided by ad spend for the selected date range."
  expanded={open}               // collapsed by default
  onToggle={setOpen}            // click / Enter / Space on the header row
>
  {children}                    // optional slot content (Show Slot)
</Accordion>

<!-- rendered -->
<div class="accordion">

  </button>

</div>

Source

Values come from the Accordion — Documentation frames on the Accordion page of the Cube Core Figma file (Anatomy, Property, Color Annotation, Dimensions, API, Usage Guidelines, How to use) and the live Accordion component set (3 styles × Collapsed / Expanded).

Where Figma disagrees with itself or leaves gaps: the colour table gives Primary-text/900 for the icons, but the component’s 16px icons use text/text-primary (#101214) and the Prominent caret Primary-text/800 (#3e464c) — this page shows the component. The slot is called “Slot” on Prominent and “Slot 2” on Bordered and Underline. In Figma the header uses fixed gaps (219 / 250 / 331); build it as space-between so the icon stays on the right at any width. The Prominent cards example is wider (673–933) than the 520 component, so it fills its section here. The nesting Don’t in Figma stacks a Bordered accordion under a Prominent one; this page draws it inside the Prominent slot. There are no hover or focus variants yet — the focus ring here follows the API’s “visible focus ring on header”.
