Button

Stable Last updated Sep 2026

A clickable control that triggers an action. Three families — Action, Neutral and Accent — share one anatomy: a container, optional prefix and suffix icons, and a text label, plus an icon-only mode.

API

Width hugs content. Variant axes (Variant, Action Type, Size, Height & Spacing, State, Rounded, Icon-Only) are Figma variant properties; Button Text, Show Prefix / Suffix and Prefix / Suffix Value are component properties. The code column is the matching prop on the Storybook Button.

Button Textstring“Accent”—Default text differs from the other families.

Figma ↔ code gaps. Storybook’s Button has no props for Accent colours, the Dashed variant or Neutral Dark mode, and adds values Figma doesn’t have (variant tonal / subtle, intent ambient / chrome, sizes xs / xl / xxl, loading). Treat the Figma set as the design contract and flag any gap to engineering. Icon-only buttons are IconButton (icon, ariaLabel); SemanticButton takes just label and intent.

Color tokens

The design-token mapping per state for each family. Label and icon always share the same token. A dash (—) means “same as Default”. Names drop the shared Semantics/ prefix (so Disabled/100 is Semantics/Disabled/100). Hover a swatch for its hex; the token name is the contract.
