Segmented Control

New Last updated Oct 2026

A row of connected options where exactly one is active — used to switch views, periods or modes instantly. A Segmented-control (the track) holds 2–8 Segmented-elements (the options). Three types: Primary (solid, high emphasis), Secondary (tinted, low emphasis) and Accent (colour-coded).

Guidelines Specifications Code (opens Storybook in a new tab) Accessibility (coming soon)

At a glance

Try it: switch the period above the chart, or the metric in the card. The view changes the moment you click — there’s no Apply button. Tab into a control, then use ← →.

Selected: Daily · Units

Primary · Small above a chart, and Secondary · Small inside a card.

1 · Track

The Segmented-control — a white container that holds the options edge to edge.

2 · Segments

The options (Segmented-elements). 2–5 short labels work best.

3 · One selected

Exactly one segment is always active, and it applies immediately.

When to use

Use for 2–5 short, mutually exclusive options that change the view immediately (period, metric, chart / table). For choices inside a form use Radio; for 6+ options use a Dropdown; for switching whole page sections use Tabs.

You need to…UseWhy
Switch a view, period or metric instantly (2–5 options)Segmented controlAll options visible; one click, no confirm.
Pick one value that is saved with a formRadio / Selection groupThe choice waits for Save / Submit.
Pick from 6 or more optionsDropdownA segmented row gets too long and cramped.
Move between whole sections of a pageTabsTabs own a panel of content below them.
Turn one setting on or offToggleA single binary setting, not a choice between views.

Anatomy

1 · Segmented-control (track)

Selection/Segmented-control — the container that holds the options. Shown: Primary, Medium, Width = Fit, 4 tabs, at 2×.

#ElementFigmaNotes
1TrackframeWhite container, 1px Secondary-text/100 border, radius 8 (100 when Is Rounded = Yes), padding 2. No gap — segments sit edge to edge.
2Selected segmentinstanceExactly one segment is selected at any time. Primary: solid Primary/600 with white text.
3Un-selected segmentinstanceOther options — white / transparent with Secondary-text/700 text.
4Tab 3 / Tab 4instanceBoolean properties turn extra segments on. Tab 3 and Tab 4 are on by default; Tab 5–8 can be enabled (max 8).
5Last segmentinstanceWidth = Fit hugs each label; Width = Fill or Fixed stretches all segments equally to the track width.

2 · Segmented-element (option)

Selection/Segmented-element/Primary — one option. Shown: Medium, Selected, with Prefix Icon, Pro and Count enabled, at 3×.

#ElementFigmaNotes
1Segment containerframePadding 4 / 10 (Small), 6 / 12 (Medium), 0 / 14 at a fixed 32px height (Large). Gap 4. Radius 6 (8 on Secondary Large).
2Prefix iconinstanceOptional “Show Prefix Icon” + “Prefix Icon” (instance swap, default Cube). Use for view icons (chart / table).
3LabeltextTEXT property “Text”. Medium 12/16 (14/18 Large); SemiBold when selected. 1–2 words.
4Pro taginstanceOptional “Pro” — premium option. White variant on selected Primary / Accent segments.
5Count chipinstanceOptional “Show Count” (Primary, Secondary) — number badge, e.g. items per view.

3 · Element types

The three segment types, selected state, at 2.5×. The track Type must match the element type.

#ElementFigmaNotes
1PrimaryinstanceSolid Primary/600, white SemiBold text. Highest emphasis — the main view switch on a page.
2SecondaryinstancePrimary/100 fill + Primary/400 border, Primary/700 text. Lower emphasis — secondary filters, inside cards and popovers (used in the Date selector).
3AccentinstanceColour-coded selected state (e.g. MRP vs SP). Small / Medium only, max 3 options.
4Accent-backgroundinstanceNested colour layer: Pink · Purple · Green · Bronze Green · Orange · Teal (Accent/*/600). Swap its Color variant to change the accent.

4 · Disabled & Locked

A segment can be disabled on its own. “Locked” adds a lock icon to explain why. Shown: Primary, Medium, at 3×.

#ElementFigmaNotes
1Disabled segmentframeDisabled/50 fill. Can’t be selected; other segments stay interactive.
2Disabled labeltextDisabled/500 (Primary / Accent) or Disabled/400 (Secondary).
3Pro taginstancePair with Locked when the option needs an upgrade.
4Lock iconinstance“Locked” — only shown on disabled segments. Add a tooltip with the reason.

Type

Set on the track; it decides which element type is used inside. Pick by emphasis.

Primary Default

Solid selected segment. The main view / period switch on a page.

Secondary

Tinted selected segment. Secondary filters, cards, popovers.

Accent

Colour-coded selection (e.g. MRP vs SP). Rounded only, max 3 options, Small / Medium.

Size

Height of the segments (the track adds 2px padding on each side — except Secondary, which has none).

Small

24px segments, 12px text. Dense toolbars, cards.

Medium Default

28px segments, 12px text.

Large

32px segments, 14px text. Page-level switches. Not available for Accent.

Width & shape

How segments share the space, and the corner style of the track and segments.

Width = Fit Default

Each segment hugs its label. Default for most uses.

Width = Fill or Fixed

All segments equal width, stretched to the track width (400 here). Use when the control spans a card or panel.

Is Rounded = No Default

8px track, 6px segments — matches cards and fields.

Is Rounded = Yes

Pill shape. Use in chip-like contexts and for Accent.

Tab count

Boolean properties Tab 3 … Tab 8 on the track turn segments on. Default: 4 (Tab 3 + Tab 4 on). Turn off Tab 3 / 4 for 2 options; turn on Tab 5 → 8 for more. Keep to 2–5 in practice — beyond 5, prefer a Dropdown or Tabs.

Segment states

Each segment is Un-selected, Selected or Disabled. Primary sets this with one State property; Secondary and Accent use separate Selected + Disabled properties. Shown at Medium.

TypeUn-selectedSelectedDisabled
Primary
Secondary
Accent
  • Un-selected — white (Primary, Accent) or transparent (Secondary), Secondary-text/700, Medium weight.
  • Selected — Primary/600 + white · Primary/100 with a Primary/400 border + Primary/700 · the Accent colour + white. SemiBold.
  • Disabled — Disabled/50 + Disabled/500 (Primary, Accent) or Disabled/400 text only (Secondary).

Segment add-ons

Optional toggles on each segment, shown here at 2×. All three (icon, Pro, count) can be on at the same time.

Show Prefix Icon

Leading icon (swap via “Prefix Icon”).

Pro

Premium marker. Turns white on a selected Primary / Accent segment.

Show Count

Count chip (Primary / Secondary only). Turns blue when selected.

Locked

Disabled segments only. Add a tooltip with the reason.

Icon-only look

Prefix icon + empty text — needs a tooltip and an aria-label.

Accent colours

Accent-background — the colour of a selected Accent segment. Swap the Color variant on the nested layer. Pick the colour of the chart series the control drives, so the switch and the data read as one.

Pink (default) · Purple · Green · Bronze Green · Orange · Teal. ⚠ “Teal” is bound to Accent/Light Blue/600.

Common layouts

Primary for the main switch on a chart or page, Secondary for low-emphasis switches inside cards and popovers, Accent when the selected colour must match the chart series it controls.

Do’s and don’ts

Do

Use 2–5 short options.

Don’t

Don’t squeeze 6+ options into a segmented control — use a Dropdown.

Do

Keep labels to 1–2 words of similar length.

Don’t

Don’t use long or uneven labels — segments become lopsided.

Do

Use one Primary control per area; use Secondary for nested or lesser switches.

Don’t

Don’t stack several Primary controls together — nothing stands out.

Do

Use segmented controls for actions that switch a view instantly.

Don’t

Don’t use it for choices that need a Save / Submit — use Radio in forms.

Do

Use Accent only when the colour matches the data it controls.

Don’t

Don’t use Accent as decoration — use Primary instead.

Writing content

  • Labels — 1–2 words, similar length, sentence case: “Daily”, “Units”, “Chart”.
  • Parallel — all options of the same kind (all periods, all metrics). Don’t mix “Daily” with “Show table”.
  • Order — a natural order (Daily → Weekly → Monthly) or most-used first. The default selection is usually the first.
  • Abbreviations — only well-known ones (D / W / M, MRP / SP) and only where space is tight.
  • Icon-only — every icon-only segment needs a tooltip and an accessible name.

Behavior & accessibility

TopicWhat to do
SelectionExactly one segment is selected — never zero. Default to the first segment (or the saved view).
ChangeApplies immediately on click / tap. No confirm step, no Apply button.
Semanticsrole="radiogroup" on the track with an aria-label, role="radio" + aria-checked on each segment. Use tablist / tab instead when it switches panels of content.
KeyboardTab focuses the selected segment; ← → move and select; Home / End jump to the first / last. Disabled segments are skipped.
Disabled / LockedKeep the segment visible so people know the option exists; explain why in a tooltip.
OverflowNever wrap onto a second line. If labels don’t fit, switch to a Dropdown.
