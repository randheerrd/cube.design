Subscription card

New Last updated Nov 2026

The plan card on pricing and subscription pages. Each card shows one plan — name, price, discount, what’s included and allowances — and one action that reflects the user’s relationship with that plan: add, switch, upgrade, downgrade or active. Place 3–4 side by side to compare plans. The Specifications tab lists every value.

Guidelines Specifications Code (not in Storybook yet) Accessibility (coming soon)

At a glance

A pricing card for one plan. The header says what the plan is and what it costs; the Content slot lists what’s included; the Plan Action at the bottom shows where the user stands with that plan — add it, switch to it, upgrade, downgrade, or “Active” if it’s theirs.

Use it for

Pricing and “Manage plan” pages: 3–4 plans side by side, lowest to highest, with the same features in the same order.

Built from

① Card (header + Content slot) with ② _Plan Action at the bottom. The slot holds ③ Plan Features or ④ Plan Tokens.

One action per card

Exactly one card is the Current plan (Active); every other action is relative to it. Turn Action off in modals.

How it’s built

One card per plan. Fill its Content slot with Plan Features (platform plans) or Plan Tokens (module plans), then set the nested _Plan Action to the user’s state.

① Subscription card

The plan card. Header (name, current-plan badge, price, discount, description) + “Content” slot + Plan Action. Trial = Yes adds the gradient “Free for N days” banner.

② _Plan Action

The card’s button. Shows where the user stands with this plan: Add to cart · Added to cart · Switch plan · Active · Upgrade · Downgrade · Downgrade scheduled.

③ Plan Feature

One included feature: check + text. Highlight (brand blue) for the “Everything in …, plus” line.

④ Plan Token

An allowance for module plans (e.g. GobbsIQ): Tokens (wallet icon) or Questions (? icon) per month.

Anatomy

One plan, top to bottom: optional trial banner → plan name (+ current-plan badge) → discount + original price → price + billing period → one-line description → dashed divider → “Includes” content slot (Plan Features, Plan Tokens) → Plan Action button.

Common layouts

Use subscription cards on pricing / “Manage plan” pages. Show 3–4 plans side by side, lowest to highest, with the same features in the same order so users can compare. Exactly one card shows “Current plan”; each card’s action reflects the user’s relationship to that plan.

Writing content

  • Plan name — the tier only: “Lite”, “Standard”, “Pro”.
  • Price — the amount with the rupee sign and separators (“₹11,250”), or “Free”. Always followed by the billing period.
  • Billing period — what the price covers: “Monthly / Platform”. Never remove it.
  • Discount — set Original price (“₹15,000”) and edit the % in the chip (“25% Off”). The chip value isn’t a property; never show the chip without the original price.
  • Description — one line on what the plan is for: “Go deeper, down to each dark store”, “Track the basics across platforms”, “Full automation with dedicated reviews”.
  • Features — “Includes:”, then one Highlight line, “Everything in <previous plan>, plus”, then the features as Default lines — the same ones, in the same order, on every card.
  • Allowances — Plan Token value + label: “3000” · “GC Tokens per month”.
  • Action labels — name the plan the action leads to: “Upgrade to Standard”, “Downgrade to Standard”, “Switch to Standard”; Active reads “Active since 5 Aug’26”. Labels aren’t text properties — edit the button or chip.
  • Trial — “Free for 7 days”, with the real trial length.

How to add one in Figma

Build a plan comparison in five steps.

  1. Place one card per plan
    Assets → “Subscription card”. Put 3–4 in a horizontal auto-layout (16px gap), cheapest first.
  2. Fill the header
    Plan name, Price, Billing period, Description. Discount on: set Original price and edit the % chip.
    Properties panel: Plan name “Standard” · Price “₹11,250” · Discount On.
  3. List the features
    In the Content slot: “Includes:”, then Plan Features — first one Highlight (“Everything in Lite, plus”), the rest Default. Add Plan Tokens for allowances.
    Properties panel: Plan Feature · Type Highlight · Feature text.
  4. Set the action
    Select the nested _Plan Action and pick the state for this user: Add to cart, Active, Upgrade, Downgrade… (see the action table on the Specifications tab).
    Properties panel: Action Upgrade.
  5. Mark current plan / trial
    Current plan on (with Active) for the user’s plan. Trial = Yes only on the plan with a free trial.
    Properties panel: Current plan On · Trial Yes.

Before you hand off

  • 3–4 plans, cheapest first, same feature order.
  • One Current plan with Active; other actions relative to it.
  • Price + billing period on every card; discount shows original price.
  • Action labels name the right plan (edit “to Standard” text).
  • Trial banner only on the trial plan.
  • Card heights aligned in the row.
