Pie chart

A donut that shows how one total splits into a few parts (2–6): share of platforms, a rating split, where a loss came from. An optional centre label carries the total, and a legend sits beside or below the ring.

Cube Core

Figma
Guidelines Specifications Code (not in Storybook yet) Accessibility (coming soon)

At a glance

One donut for every pie in the product. Size sets the diameter, Legend puts the key to the right, below, or nowhere, and Style picks a categorical palette or one hue in steps. The ring itself is a nested Donut (Segments and Thickness) and every legend row is a nested _Pie legend item, so the chart, its segments and its legend are all set from one panel. Change the properties below and hover a segment to read it.

Use it for

How one total splits into a few parts (2–6): share of platforms, a rating split, where a loss came from.

Pick the style

Colour when the parts are different things (platforms, brands, ratings). Monochrome when they are pieces of one total (reasons, buckets).

Not a pie chart

Comparing values across items or over time: use a bar chart or Trends. Lengths are easier to compare than angles.

Donut_Pie legend item

The controls are the component’s own properties, in the order of the Figma panel. As in Figma, the legend rows (Item 3–6) and the Donut’s Segments are set separately — keep them equal. Legend values follow the segments here; in Figma each row’s Label and Value are text you edit.

How it’s built

One public component and two private building blocks.

① Pie chart

The component you insert. Size Small / Medium / Large · Legend Right / Bottom / None · Style Colour / Monochrome. Centre: Value + Delta + Sub-text (toggles). Legend items 1–6 (Item 3–6 are toggles).

② _Donut

Private; exposed in the Pie chart panel. Segments 1 (Ring = one value on a track) to 6 · Thickness Thin / Regular / Thick · Style. Segments use preset sizes: edit a segment’s Arc to set real proportions.

③ _Pie legend item

Private. One legend row: swatch + label + value. Position 1–6 = segment colour · Order Label first / Value first · Show swatch / label / value / info.

Common layouts

Use a pie chart to show how one total splits into a few parts (2–6) — share of platforms, rating split, where a loss came from. Use Colour when the parts are different things (platforms, brands, ratings) and Monochrome when they are pieces of one total (reasons, buckets). For comparing values across items or over time, use a Bar chart or Trends instead. Hover the segments below.

Five rules from the Pie chart usage guidelines. Each pair shows the right and wrong way, and why.

Segments

Do

Keep it to 6 segments or fewer; group the rest as “Others”. Why: small slices are hard to read and compare.

Don’t

Don’t show many tiny slices. Why: nobody can tell 2% from 3%.

Do

Don’t leave extra legend rows. Why: users look for slices that aren’t there.

How to add one in Figma

Step-by-step for designers.

Add a pie chart in 5 steps

  1. Insert and pick Size & Legend
    Assets → “Pie chart”. Small for cards, Medium for widgets, Large for reports. Legend Right (default), Bottom for narrow cards, None when cards act as the legend.
  2. Choose Style
    Colour for different categories; Monochrome for one total broken down.
  3. Set segments and thickness
    Select the nested Donut: Segments (Ring, 2–6) and Thickness. Then switch Item 3–6 so the legend has the same number of rows.
  4. Fill the centre and legend
    Value (total) + Delta + Sub-text, or turn the centre off. Edit each legend item’s Label and Value; use Value first for “share of total” lists.
  5. Adjust proportions
    Segments use preset sizes — select a segment and edit its Arc (start / sweep) to match the data.

Before you hand off

  • A pie chart is right: one total, 2–6 parts.
  • Style fits: Colour for categories, Monochrome for one total.
  • Legend rows = segments (count and order).
  • Segments sorted largest first; small ones grouped as “Others”.
  • Centre shows the total (or is off); text fits the hole.
  • Segment arcs match the real data.

Every dimension, colour token and property is on the Specifications tab.
