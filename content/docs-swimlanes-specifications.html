Swimlanes

Swimlanes compare a few items side by side: each column is one item (a brand, category or platform) and each row is one metric. People scan across a row, select a column to focus on it and drill down from it. The Specifications tab lists every value.

API and behavior

Designers: put Swimlanes-composition in a Dashboard-widget slot, fill the Columns slot with one Swimlane-Column per item and each column with one Swim Lane Card per row. Developers: render from data { rows: metrics[], columns: items[] } — the label column and every column read the same rows array so heights always line up.

<Swimlanes
  rows={[
    { key: "sales", label: "Sales", type: "amount", subMetrics: ["units"] },
    { key: "share", label: "Est. Cat. Share", type: "percent" },
    { key: "dsCoverage", label: "Brand’s DS Coverage%", type: "percent", locked: !plan.has("dsCoverage") },
  ]}
  columns={categories}          // [{ id, name, values: { sales: { value, delta, abs }, … } }]
  selectedId={selected}         // one column at a time
  onSelect={setSelected}
  onDrilldown={openCategory}
  actions={["View Trends", "Competition", "Cross Platform"]}
  emptyText="No Results found"  // shown when columns is empty
/>
TopicRuleNotes
Select columnClick header / columnSelected column highlights; drilldown targets it.
Row alignmentSame rows array everywhereCard heights per row are equal across columns and labels.
OverflowHorizontal scrollLabel column stays fixed (sticky) while columns scroll.
LockedShow Locked card, not emptyUpgrade link → plans page.
EmptyEmpty = YesAfter search / filter with no matches.
SortingOptional by rowOrder columns by the selected row metric.

Source

Values come from the Swimlanes — Documentation frames on the Swimlanes page of the Cube Core Figma file (Anatomy, Property, Color Annotation, Dimensions, API, Usage Guidelines, How to use) and the live Swimlanes-composition, Swimlane-Column, Swim Lane Card and Swimlane-labels components in Swimlanes · components (use these).

Where Figma disagrees with itself or leaves gaps: the API tables default Selected to Yes, but both components ship with it off — this page says No. The colour table gives Primary-text/300 for selected sub-metric text; the selected card actually uses Primary-text/700, which is shown here. The selected column’s Drilldown, divider and button colours and the 80% footer opacity aren’t in the colour table; they’re read from the component. The unselected Locked card is 86 tall and the selected one 84; 84 is used. The Don’t for “12 columns” in Figma shows the same 6 columns as the Do; this page draws the squeezed version. Column headers in the components read “Header”; examples here use real category names. In the in-context screen columns 2–6 are 192 wide; the component width, 196, is used.
