Swimlanes

New Last updated Oct 2026

A side-by-side comparison view: each column is one item — a brand, category or platform — and each row is one metric. People scan across a row to compare, select a column to focus on it, and drill down from it. The Specifications tab lists every value.

Guidelines Specifications Code (not in Storybook yet) Accessibility (coming soon)

API and behavior

Designers put Swimlanes-composition in a Dashboard-widget slot, fill the Columns slot with one Swimlane-Column per item and each column with one Swim Lane Card per row. Developers render from data — { rows: metrics[], columns: items[] } — so the label column and every column read the same rows array and heights always line up.

<Swimlanes
  rows={[
    { id: "sales", label: "Sales", type: "amount", subMetrics: ["units"] },
    { id: "catShare", label: "Est. Cat. Share", type: "percent" },
  ]}
  columns={categories}            // [{ id, name, values: { sales: { value, delta, … } } }]
  selectedId={selectedId}
  onSelect={setSelectedId}
  drilldown={(item) => openDetail(item)}
  actions={["viewTrends", "competition", "crossPlatform"]}
  emptyState={<EmptyState size="m" title="No Results found" />}
/>
RuleValueNotes
Select columnClick the header or columnThe selected column highlights; the drilldown targets it.
Row alignmentSame rows array everywhereCard heights per row are equal across columns and labels.
OverflowHorizontal scrollThe label column stays fixed (sticky) while the columns scroll.
LockedShow a Locked card, not an empty cellUpgrade link → plans page.
EmptyEmpty = YesAfter a search or filter with no matches.
SortingOptional, by rowOrder columns by the selected row’s metric.

Source

Values come from the Swimlanes — Documentation frames in the Cube Core Figma file (Anatomy, Properties, Color Annotation, Dimensions, API, Usage Guidelines, How to use) and the live Swimlanes-composition, Swimlane-Column, Swimlane-labels and Swim Lane Card components.

Where Figma disagrees with itself: the API frame gives Selected a default of Yes on both Swimlane-Column and Swim Lane Card, but the guidelines want exactly one selected column — set Selected = No on every other column and its cards. The Dimensions frame lists the % card at 56 tall, but the components show it at 84 when a sub-metric is on, like Amount. Sub-metric text and delta values are layers, not properties, so they have to be edited by hand in Figma. The Figma examples label rows “Brand A: 85%” and similar; this site uses real metric names.
