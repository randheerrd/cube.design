Skeleton

New Last updated Nov 2026

Grey placeholders shown while content is loading. They mirror the shape of the real content (text lines, values, charts, avatars), so the page feels faster and doesn’t jump when data arrives. Use the base shapes to build any layout, or a ready-made pattern.

Guidelines Specifications Code (not in Storybook yet) Accessibility (coming soon)

Motion

The shimmer isn’t drawn in Figma; it’s specified in the API frame’s behaviour rules for developers.

API and behavior

Designers: build the loading state from base shapes or a pattern, matching the real layout. Developers: <Skeleton shape="text|block|circle" width height /> with a shimmer animation; render inside the same container as the real content and swap when data arrives.

<section aria-busy={loading}>                              // the region that loads
  {loading ? (
    <>
      <span className="sr-only">Loading …</span>
      <Skeleton shape="text"  width="50%"  height={12} />  // title
      <Skeleton shape="block" width={150}  height={32} />  // value
      <Skeleton shape="text"  width="50%"  height={10} />  // caption
      <Skeleton shape="block" width="100%" height={120} /> // chart
    </>
  ) : (
    <MetricCard {...data} />                               // same size — no jump
  )}
</section>

// Skeleton renders aria-hidden="true" and appears after ~300ms.
// Shimmer: 1.2–1.5s, left → right; static under prefers-reduced-motion.

Source

Values come from the Skeleton — Documentation frames on the Skeleton page of the Cube Core Figma file (Anatomy, Property, Color Annotation, Dimensions, API, Usage Guidelines, How to use) and the live Skeleton component and Skeleton / patterns (Text lines, List item, Table cell, Card, Plan card) in Skeleton · components (use these).

Where Figma disagrees with itself or leaves gaps: the shimmer isn’t built in Figma — the colour table marks it “Not in Figma ⚠” and the API frame recommends a White @60% sweep, left → right, 1.2–1.5s; this page animates it at 1.4s, linear (no easing is given). There is no dark variant; Figma suggests a White @8–10% fill, which isn’t shown. Anatomy says the Text shape matches the text line height, while Dimensions says the text cap height (10 for 12px text, 12 for 14px, 16 for 20px); the component default, 12, is used. The behaviour rules say 5–10 table rows; the Table loading example says 4–10 and draws 4. The loaded card in the in-context frames uses a hard-coded #e3e6ea border; the skeleton card uses border/border-secondary (#e3e7ea). The Property frame’s size row shows circles at 24 and 40 only (32 is the default). In the base-shapes anatomy, Figma’s marker 2 sits on top of the circle; here it points down. The loose “Examples” frame of product screenshots next to the board isn’t documentation and is left out.
