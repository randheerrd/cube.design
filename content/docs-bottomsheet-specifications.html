Bottom sheet

A full-width panel that rises from the bottom over a dimmed page. Use it for a deep, wide view of something the user clicked — a full table or a side-by-side analysis — while keeping the page behind it.

API and behavior

Designers: place Bottom-sheet at the bottom of the screen frame over a scrim, set the header, choose Divided, and fill the slots. Developers: <BottomSheet title switcher={{label,value,onPrev,onNext}} divided tabs left={…} right={…} onClose /> — a modal sheet with focus trap.

<BottomSheet
  title="Category RCA"            // Heading — what the sheet shows
  switcher={{                     // Switcher (on by default): for ‹ Label: Value ›
    label, value,
    onPrev, onNext,               // step through items without closing
  }}
  divided                         // default true: left + grey right panel
  tabs={false}                    // left-panel tabs
  left={…}                        // Communication/Message, Table-template
  right={…}                       // Trends-composition, Table-template, Message
  onClose={close}                 // ×, Esc or a click on the scrim
/>

<!-- rendered -->
<div class="scrim"></div>                         <!-- black 40% -->
<div role="dialog" aria-labelledby="bs-title">    <!-- focus trapped inside -->
  <header>                                       <!-- fixed -->
    <h2 id="bs-title">Category RCA</h2> for ‹ Label: Value ›
    <button aria-label="Close">…</button>
  </header>
  <div class="content">…</div>                    <!-- scrolls -->
</div>

Source

Values come from the Bottom sheet — Documentation frames on the “Bottom Sheet /overlays” page of the Cube Core Figma file (Anatomy, Property, Color Annotation, Dimensions, API, Usage Guidelines, How to use) and the live Bottom-sheet, Bottom-sheet-Header and Right Overlay-Divided-Panel components.

Where Figma disagrees with itself or leaves gaps: the sheet uses the old “Flat White” style and the header a raw #FFFFFF — both should be Neutrals/White/100. The corner radius is 0, though Figma recommends 16 on the top corners; this site follows the component. The scrim is not part of the component; Figma recommends Neutrals/Black/40. The header anatomy lists Tabs (Primary, Large, indented) and the Dimensions give +38 with tabs, but Bottom-sheet-Header has no Tabs property — its API lists Heading, Switcher and Description only. The colour table gives Regular 12 for the description; the header description renders Regular 14 / 18, and 12 / 16 is the content-heading description. The content heading is bound to the Size/18 and Line-height/24 variables but renders 16 / 20, in raw black. The anatomy gives the left slot padding as 16 / 24; the Dimensions table and the component use 16 / 24 / 24. Some gaps are raw numbers rather than Spacing tokens: the right panel’s side padding (24) and gap (20), the header gaps (8, 6, 2) and the content heading gap (4). The right half is still named “Right Overlay-Divided-Panel”, and the switcher layer is called “City switcher” although it switches any item.
