Components

Bottom sheet

Stable Last updated Oct 2026

A large panel that slides up from the bottom over a dimmed page, for a deep, wide view of something on the page without leaving it. The Specifications tab lists every value.

Guidelines Specifications Code (not in Storybook yet) Accessibility (coming soon)

API and behavior

Designers place Bottom-sheet at the bottom of the screen frame over a scrim, set the header, choose Divided and fill the slots. Developers build it as a modal sheet with a focus trap.

<BottomSheet
  open={open}
  onClose={close}            // ×, Esc, scrim click
  heading="SKU details"
  switcher={{
    label: "SKU",
    value: sku,
    options: skus,
    onChange: setSku,        // previous / next / pick
  }}
  divided
>
  <BottomSheet.Left heading={sku.name} description="Offtake ₹57.4 L · Wt. OSA% 76.2%">
    <Message>Data till 12 May’26</Message>
    <TableTemplate rows={rows} />
  </BottomSheet.Left>
  <BottomSheet.Right tabs={["Trends", "Details"]}>
    <TrendsComposition metrics={metrics} data={series} />
  </BottomSheet.Right>
</BottomSheet>

Source

Values come from the Bottom sheet Documentation frames in the Cube Core Figma file (Anatomy, Property, Color Annotation, Dimensions, API, Usage Guidelines, How to use) and the live Bottom-sheet, Bottom-sheet-Header and Right Overlay-Divided-Panel components.

Where Figma disagrees with itself or has gaps: the sheet uses the old “Flat White” colour and the header a raw #FFFFFF; this site uses Neutrals/White/100 for both. The scrim is not part of the component; Figma recommends Neutrals/Black/40. The corner radius is 0, though Figma recommends 16 on the top corners; this site follows the component. The right half is still named “Right Overlay-Divided-Panel”. The content heading uses the size/18 variable but renders at 16. The API frame leaves the developer component name blank, and the switcher layer is called “City switcher” even though it switches any item. Most spacing is bound to Spacing tokens, but some gaps are raw numbers: the right panel’s side padding (24) and gap (20), the header gaps (8 between heading and switcher, 8 after “for”, 6 between the switcher buttons, 2 between heading and description) and the content heading gap (4). This site uses the same values; bind them to Spacing/24, /20, /8, /6, /2 and /4.
