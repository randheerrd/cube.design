Radio

API and behavior

State and Disabled are separate axes — combine them, for example Selected + Disabled. In code a radio group holds one value; Hover and Hovered come from pointer events.

Source

Values come from the Radio — Documentation frames in the Cube Core Figma file (Anatomy, Property, Color Annotation, Dimensions, API, Usage Guidelines) and the live Selection-control/Radio, Radio-inline and Radio-chip components. Figma has no “How to use” frame for Radio.

Where Figma disagrees with itself (this site follows the component unless noted): the API gives the control’s default Size as 16; the component’s is 14. The docs say Show Color Legend has no effect, but it shows a purple square on every chip without a description. On Large Radio-inline the selected label shrinks to 12/16 — a component bug; this site keeps 14/18 as documented. The Large chip with a description is radius 6 when selected and 8 otherwise. The selected centre is knocked out, not white. Ring widths are 0.96 / 1.12 and 3.36 / 3.92, not 1 and “about 4”. The Count and Recommended colours change with state, which the Color doc leaves out. Description is a variant (Large only), not an optional toggle. The docs say to use a prefix icon or a platform logo, not both, but the component allows both. The control uses “Hover” while inline and chip use “Hovered”. There is no focus or error state.
