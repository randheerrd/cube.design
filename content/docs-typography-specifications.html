Typography

Stable Last updated Oct 2026

Every type style's family, weight, size, line-height and letter-spacing — the exact build. The Guidelines tab covers which one to pick.

Guidelines Specifications

Heads-up. Weight variables store “Semibold” / “Semibold Italic” while DM Sans calls the style “SemiBold”. Figma resolves it, but code should map by numeric weight (600), not by the string.

Family

Font families. Scope: font family.

VariableValueUsed by styles
Family/title"DM Sans"H1, H2, H3, H4, H5, H6, H6-Medium
Family/body"DM Sans"B1, B2, B3, B3-Compact, S0, S1, S1-Compact, S2
Family/Currency icon"Icomoon"Currency symbol icon font (₹) — not a text style

Title and Body are two separate variables that currently hold the same value. Reference Family/title for Heading styles and Family/body for Body/Small styles, not a hardcoded "DM Sans" — if either typeface changes later, only that one variable needs to update.
