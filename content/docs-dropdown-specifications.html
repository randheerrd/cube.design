Dropdown

Stable Last updated Oct 2026

Lets people choose one or more options from a list that opens on demand. A field (the closed trigger) opens a menu of options, groups, a header and a footer; the Specifications tab lists every value.

API and behavior

Designers: place a Dropdown field, and a Dropdown menu 4px below it when showing the open state. Developers: the field and the menu are one component in code — the field’s State is Focused while the menu is open.

TopicRuleNotes
Open and closeClick the field, or Enter, Space or the down arrowClose on Esc, a click outside, or selecting (single-select).
KeyboardUp and down move, Enter selects, type to searchFocus moves to Search when it is shown.
Single-selectA click selects and closesThe field shows the label; Value Filled = Yes.
Multi-selectA click toggles; Apply commitsClosing without Apply discards changes. The field shows chips or “+N”.
Select allChecks all visible (filtered) itemsThe parent shows Intermediate when partly selected.
Positioning4px below the field; flip up near the bottomThe menu’s minimum width is the field’s width.
Empty searchShow “No results”No empty-state variant exists yet.
