Side Nav

Stable Last updated Oct 2026

The left panel people use to move around the product: a workspace switcher, the top-level pages, a platform filter, expandable module groups and a footer, in Light and Dark mode. The Specifications tab lists every value.

Mode defaults differ by part in Figma (Light for the navbar, nav item and Knowledge base; Dark for the rest). Set Mode on Navbar-V3 and every part follows.

API and behavior

Designers: place Navbar-V3, pick the Mode, then set which item is Selected and which module is expanded inside the instance. Developers: render from a navigation config (pages → modules → sub-pages); the Selected state comes from the current route.

TopicRuleNotes
SelectedFrom the current routeExactly one row Selected across all levels; its ancestors are Expanded.
Expand / collapseClick the parent rowRemember open groups per user; auto-expand the group of the current page.
LockedNot navigableShow a tooltip with the reason or upgrade path.
Platform filterGlobal contextChanges data on all module pages; persist the selection.
OverflowMiddle area scrollsHeader and footer stay fixed.
KeyboardTab / ↑ ↓ / Enter / → ←← → collapse and expand groups; aria-current="page" on Selected.
Long labelsEllipsis + tooltipNever wrap to two lines.
