Components

Message

Stable Last updated Oct 2026

A small inline strip that sits next to the content it is about — to inform, warn, confirm success or flag an error for one specific area. Choose the colour by meaning, then Type, Size and Width; the Specifications tab lists every value.

Guidelines Specifications Code (not in Storybook yet) Accessibility (coming soon)

API

Designers: pick Color x Sentiment by meaning, then Type, Size and Width; edit the text; turn on icon, buttons and close as needed. Developers: one inline-message component taking sentiment, type, size, width, icon, title?, message, actions[] and dismissible.

Behavior rules for developers

TopicRuleNotes
PlacementNext to the content it describesAbove a table, inside a card, under a field.
TruncationTwo lines when the width is fixedTooltip or “Read more” for the rest.
DismissRemovable hides the messageRemember the dismissal if it would reappear.
ActionsMaximum two, Naked buttonsThe main action is Button 1.
Semanticsrole="status" (info, success) · role="alert" (error)Don’t rely on colour — keep the icon and the text.
